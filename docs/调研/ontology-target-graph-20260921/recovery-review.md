## 根因与源码位置

1. `backend/app/services/extraction/ontology_guided/record_search.py:473`：`admit_dependency()` 在比较所有合格区域时调用 `_projected_card()`，并非只对最终选中区域调用。
2. 同文件 `:153`：`_projected_card()` 将投影卡插入共享 `cards` 字典。未选中的临时投影也因此留下缓存条目。
3. `backend/app/services/extraction/ontology_guided/executor.py:4526`：检查点保存整个 `discovery_cards` 的 ID 集合，包含上述临时缓存。
4. `record_search.py:100`：`restore()` 根据区域行的 `execution_card_id` 和待处理 `remaining.card_projection` 重建卡；未选投影没有这些恢复来源。
5. `executor.py:4579`：严格比较保存与重建的卡 ID 集合时，因此误报区域发现范围改变。

这次已经确认的是“未选中的投影进入集合，但没有恢复配方”。不能将其描述为本体或文档实际改变。
