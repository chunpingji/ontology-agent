继续使用 `upload-23c872fb-3ab1-41de-a705-dd4b162dfa09`，CMCReport 根，源文件 SHA-256 `e94822808601e73f4ba4c715c664812d4a01e42f0e4e84a6b08a3653b915daf7`。从前轮冻结原件/IR/卡片建立新实验目录，核验内容身份，保持原 8 个片段和 86 个不同证据单元。模型仍为项目 Qwen3.6-35B-A3B。

## 改动与失败模式的对应关系

1. **两阶段返回。** 第一步只发现有原文锚点的主体和非事实观察；文档根 `document` 由代码提供。对合法主体立即取回完整卡片，第二步为各主体生成固定对象键、各自独立的属性和关系字段。模型不能自填主体 ID，也不能在属性字段写关系对象。
2. **关系端点按谓词分别限定。** 每个关系字段只枚举当前已知、满足 range 的目标 ID；无候选时不生成该关系字段。属性保留原始值和引用，由已有 `normalize_literal()` 核对类型及单位，不从属性名补造来源单位。
3. **独立原文引用。** 主体、值、字段、单位、条件、图例分别引用。输入采用短引用 ID，并保存到真实 evidence_id 的映射，避免复制长哈希造成错引；不拼接多个单元冒充一条原文。
4. **保留物理表格归属。** 输入补充由原 IR 的 grid 与 span 交集核验的逻辑行列、row_span、column_span。试验锚点限制该主体的值所在行；明确跨行的产品单元可共享，但不允许跨试验借值。表头只用于字段/单位来源，不作试验主体。
5. **状态与事实分开。** N/A、图例中的 × 和 —、条件动作、无单位值可以保留为带证据的观察或未决记录。观察不写入事实集合；无法映射不能自动成为肯定或否定。

卡片召回仍为有限实验：以已知 CMCReport 的两跳正式类型空间及原文/本体标签做候选路由，每个根关系保留一个一般范围类型（本次 12 个），再补充 8 个词法候选，共 20 个候选类型；不向模型提供参考答案、期望值或旧模型输出。候选未覆盖的概念保留未决，不自动修改本体。

## 调用前验收口径

独立冻结 `schema_card_tightened_acceptance.json`，评分进程在模型调用全部结束后才读取。每片段同时要求必要正例和禁止错误：产品属性、文档根关系、设备关系、质量限度及条件、完整包装/温度/有效期、N/A 状态、两个试验的 PDE 与来源、四个毒性符号及其图例语义。PDE 两行分别要求同组属性属于同一主体、两组主体不同且锚点位于各自试验列；存放三属性要求同一 StorageCondition。关系正例必须为 affirmed。空输出不能通过。

分别报告：原生 JSON 合规率、原文/卡片约束错误、接受属性/关系数、拒绝数、观察/未决数、8 片段的信息保留与禁止项结果。技术失败、截断或未尝试计为未通过，不从分母排除。检查器通过不代替完整语义证明；本轮仍是已知单文档回归，不报告全文或跨文档 precision/recall。

## 执行和预算

- 冻结方案、参考和新协议后先执行反例测试：反向关系、非法主体、PDE 交换行、借错单位列、百分比填 μg、N/A 实体、— 真假化、× 未知化、空输出。
- 主验证每片段最多 2 次调用，总预算 16 次；若某片段没有合法主体仍检查其观察，记录是否跳过事实抽取。
- `temperature=0`，thinking 关闭，原生 `json_schema`，禁止自动回退及重试；输出上限 4,096 tokens，HTTP 超时 180 秒、含排队总预算 240 秒。
- 原始失败响应与拒绝原因保留；任何额外调试复测必须另建目录、单独计数，不覆盖首次结果。
- 复用项目客户端和共享调度；新增调用账本和实验制品，不恢复暂停作业，不写业务事实。

## 交付
