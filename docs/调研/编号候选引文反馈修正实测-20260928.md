## 证据片段 ID 方案评估

用户提出让模型返回证据原文编号。可将原文抄写任务改成程序提供片段、模型选择片段 ID，但整句 `source_id` 不能单独定位同句的两个成员。

当前 `key_occurrences` 已提供 Mock 键在原文中的精确位置和出现序号，适合作为片段目录的输入；每一处出现应有独立 ID，内部绑定文档、来源和字符范围，文本由程序切片。模型输出片段 ID 与成员分组，程序约束 ID 可选范围并核验成员、属性及边界，不再要求模型重复生成相同引文。

片段存在不证明全局身份；现有 `boundary_status=not_checked` 和 `identity_status=not_checked` 仍需保留。没有 Mock 命中的编号也必须有发现入口，不能因片段目录缺项认定不存在：可继续允许一次新片段提议并严格定位，确认后转成同样的 ID 引用。此方案尚未替换当前协议，需要独立实现和复测，不能把本轮 110 项工程通过算作片段 ID 方案通过。
