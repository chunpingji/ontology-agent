# 第二阶段原文采信实施与主服务验证

本轮按用户批准方案实施：实体登记后独立发现关系与属性，按区域/候选衔接发现和核验，
再核对冻结 Schema 卡和授权原文。新运行默认 `evidence_review`；旧运行保持冻结策略。

## 当前实现

- 关系、属性采信不依赖上层关系是否采信。实体自身类型、指称、组成证明及当前引用仍有效。
- 原文采信与规范化、SHACL 结构诊断分离；原文支持的范围或缺单位值仍可采信原值，
  规范化失败时 `normalized_value=null`、`normalization_available=false`。错误引文、
  错误单位绑定、错误主体、非法谓词/端点版本仍不能取得采信证明；`N/A` 保持缺失观察。
- 未采信/待定关系和属性保留合法端点、实际原文、逐项错误码及模型说明，不伪造证明。
- 图谱分析页面展示采信实线、待定虚线；未采信默认隐藏，可打开开关查看原因。
  隐藏不删断言、不缩小目标分母；原文值/单位与规范化值/单位分别展示，0/false 保留。
- 已完成发现但核验暂未完成时，保留当前恢复入口并暂停；候选先发布无证明修订，核验
  完成后发布预先冻结的目标修订。未知模型调用仍按原有未决处理，不自动重发。
- 沿用当前工作状态、调用账本和展示缓存，没有增加执行历史回放；未新增领域硬编码或修改 TTL。
