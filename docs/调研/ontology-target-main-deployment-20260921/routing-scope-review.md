## 表头及标题的范围差异

冻结 IR 的 12 张表均为 `header_row_count=1`。其中 T1R1 实际含“投料”及步骤一至四，T9R1 实际含安全问卷第一题；两行因此进入表头上下文，未构成独立源记录。其他十张表的首行是常规表头。不能将 38 个数据行记录宣称覆盖了全部 50 行的独立发现，也不能反过来声称那两行文字已完全丢失：后续对应表行任务可能携带 header context，本次未检查其实际提示词内全文呈现情况。

28 个标题单元也不构成独立源记录，包括封面项目/报告标题、密级及各节标题。它们可用于导航或上下文；全文参考读过这些段落，不代表系统已经把其中每项文档元数据识别成事实。

T6、T7、T10、T11 的部分合并单元格由多个逻辑行共享。JSON 同时保留记录的主要行位置与共享单元格实际位置；逐区域执行状态按主要行对应，不把共享的产品名称或步骤标签被读取当成整行已执行。

本报告未计算 precision/recall 或关系、属性事实完整度。后续继续、依赖触发或路由改变都可能扩大执行范围；需要在新的明确时点重新读取，不能把这里的暂停快照称为最终全文结果。
