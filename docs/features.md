# 项目特性功能总览

> 临床药物共线生产风险评估智能辅助平台，更新于 2026-07-09。

| 一级功能 | 二级功能 | 功能描述 |
|---------|---------|---------|
| **知识建模与治理** | 领域知识库管理 | 构建和维护药品生产风险评估领域知识模型，支持版本迭代与发布 |
| | 风险规则可视化配置 | 以声明式方式编辑风险评估规则，绑定到具体评估维度，无需编码 |
| | 规则自动推断与溯源 | 根据药品属性自动推断风险分类，并关联法规依据形成溯源链 |
| | 规则模板与版本管理 | 预置常用风险评估规则模板，支持规则版本化迭代与导入导出 |
| | ALCOA+ 合规支撑 | 数据完整性符合 ALCOA+ 原则，支持电子签名与哈希链校验 |
| **智能文档处理** | 文档上传与自动解析 | 上传 Word/PDF/Excel 文档，自动解析文档结构与内容 |
| | 实体自动识别与提取 | 智能识别文档中的药品、设备、工艺参数等业务实体 |
| | 表格数据精准提取 | 准确处理合并单元格、嵌套表格等复杂表格结构，不重复不遗漏 |
| | 提取结果人工审核 | 可视化查看和修正自动提取结果，支持标记"不适用"与重新标注 |
| | 文档事实溯源 | 报告中每条事实可追溯到源文档原文位置，支持跨文档证据聚合 |
| | 离线运行支持 | 全流程本地运行，无需外部网络连接，满足 air-gap 合规要求 |
| **多源数据接入** | 数据库数据源接入 | 可视化配置数据库表到知识模型的映射关系，声明即运行 |
| | API 数据源接入 | 支持内网 REST/JSON 接口作为数据来源，统一纳入评估体系 |
| | 跨源实体对齐 | 自动检测和对齐来自不同数据源的相同实体，消除数据孤岛 |
| | 数据源管理页面 | 分类浏览数据连接器，支持连接测试与状态监控 |
| **风险评估与报告** | 自动风险等级评估 | 五维 HazID 规则自动求值，确定前/后控制措施下的风险等级 |
| | 报告模板管理 | 创建、编辑和版本化风险评估报告模板，支持多版本草稿迭代 |
| | 文档类型与模板自动匹配 | 声明映射规则，系统自动为不同文档类型选择适用的报告模板 |
| | 一键生成评估报告 | 基于提取结果和知识图谱自动填充生成符合 QS 格式的 .docx 报告 |
| | AI 辅助内容填充 | AI 自动补填缺失字段、建议模板槽位，生成符合文风的叙述段落 |
| | 章节覆盖率分析 | 按章节计算事实覆盖情况，精确标记缺失与冗余，辅助质量把控 |
| | 覆盖预检与缺失提醒 | 生成报告前自动检查覆盖完整性，缺失时弹窗确认后再生成 |
| | 报告预览与导出 | 在线预览报告内容，支持 .docx 格式下载，文件名自动关联源文档 |
| | 历史报告管理 | 查看历史生成报告列表、各报告覆盖率与版本记录 |
| **流程与协作** | 评估工作流管理 | 可配置的评估流程引擎，驱动从创建到审批到关闭的全生命周期 |
| | 高风险自动待签闸门 | 高风险结论自动进入 QA 待签状态，抑制后续动作直至签批通过 |
| | 事实变更自动召回 | 源数据变更时自动触发评估重算，确保结论与最新事实保持一致 |
| | 审批工作台 | 独立的 QA 审批入口，三栏布局展示审批队列、详情与操作时间线 |
| | 研发阶段追踪 | 按研发阶段维度检索文档和评估，标注阶段性质量侧重 |
| **权限与安全** | 角色权限管理（RBAC） | 基于角色的访问控制，按岗位职责分配功能权限（如分析师、QA、管理员） |
| | 角色与用户管理 | 创建和维护角色定义，分配用户到角色，支持多角色叠加 |
| | 功能级权限控制 | 按角色控制菜单可见性、按钮操作权限与页面访问权限 |
| | 行级数据安全（RLS） | 行级安全策略，用户仅可见其权限范围内的项目、文档与报告数据 |
| | 项目级数据隔离 | 不同项目团队间数据互不可见，防止跨项目信息泄露 |
| | 数据权限动态继承 | 数据权限沿组织架构或项目层级自动继承，减少逐条配置工作量 |
| | 操作审计日志 | 全操作审计留痕，记录谁在何时对哪条数据做了什么操作 |
| **平台与体验** | 分层导航架构 | 按本体→实体→应用→治理分层组织功能入口，清晰易用 |
| | 统一视觉风格 | 全平台统一的设计规范，现代化界面风格，功能零回归 |
| | 数据映射配置页面 | 可视化配置知识模型属性绑定，实时显示覆盖率 |
| | 报告中心 | 统一浏览已生成报告与上传文档，支持详情查看与大纲导航 |
| | 响应式适配 | 优化不同屏幕尺寸下的使用体验 |
