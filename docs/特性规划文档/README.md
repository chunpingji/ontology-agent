规划与开发依据遵循[项目宪章](../../.specify/memory/constitution.md)。进入开发时，按 `specify → clarify → plan → tasks → implement` 建立对应 Spec Kit 制品，并在专题规划中记录其实际路径；需求与验收转入正式 `spec.md` 后，以该规范为准，避免维护两份冲突的需求清单。

每项规划应区分当前实现、目标行为、待验证假设及实际交付状态。已有专题设计和历史评测保留原位置，本目录通过链接引用，不复制或改写历史结果。
