# 新药研发企业原料药 GxP 通用操作、参数与过程检查调研

调研日期：2026-09-08。主体范围：化学合成小分子原料药，覆盖工艺研发、临床试验用原料药及商业化生产；另列发酵／生物原料药的扩展项。

本文用于建立操作清单、批记录字段、过程检查表及文档抽取候选词表。监管原则来自本次实际获取并阅读的 ICH 官方指南；具体操作及字段表是依据这些原则整理的工程建议，并非指南逐项规定的强制清单，也不是某个品种的操作规程。

## 1. 核心结论与适用边界

原料药过程记录应将以下内容分开，再通过批次、工艺步骤和时间关联：

| 内容类别 | 回答的问题 | 典型内容 |
|---|---|---|
| 工艺操作 | 对什么物料、设备做了什么 | 投料、置换、吹扫、鼓泡、反应、结晶、过滤、干燥、取样 |
| 过程参数 | 在什么条件下实施 | 料温、压力、转速、流量、加料速率、置换次数 |
| 时间与事件 | 何时开始、结束，持续多久 | 达温、投料结束、反应计时开始、鼓泡起止、暂停与恢复 |
| 过程检验（IPC） | 物料或过程是否达到规定指标 | 原料残留、有关物质、水分、pH、残留溶剂、粒度 |
| 操作检查 | 规定的动作、状态和程序是否得到满足 | 气体身份正确、保护维持、管路连接正确、取样点和方法符合要求 |
| 审核与处置 | 证据是否充分，能否继续或放行 | 结果复核、允许进入下一步、偏差调查、批次批准／拒绝 |

“反应温度”是参数种类，“实际料温记录”是观察结果，“温度应满足的范围”是要求，“温度符合要求”是判定。这几项不应混成一个字段。“是否进行了取样”“取样程序是否符合要求”“样品检验是否符合标准”“是否获准进入下一步”也应分别记录。

适用边界：

- GxP 是多类质量规范的统称。原料药制造主要围绕 GMP；GLP 针对适用的非临床安全性研究，不能因为在实验室进行就将所有合成、工艺开发、QC 检测归为 GLP。GCP 主要涉及临床试验实施，不能代替试验用原料药的生产质量控制。
- 探索性工艺研发、临床用原料药制造和商业化生产的控制成熟度不同。ICH Q7 第 19 章要求临床用原料药采用与开发阶段相适应的控制、记录和独立质量批准机制，不能简单免除 GMP，也不能直接套用成熟商业化工艺的全部验证要求。[S1] §19
- 化学合成原料药应论证并记录 GMP 的起始点；Q7 通常从规定的原料药起始物料投入工艺开始适用。起始物料不等于企业采购的任意第一种化学品。[S1] §1.3；[S2] §5
- 每个品种只选择实际涉及的单元操作。以下表格不是固定生产顺序；反应、萃取、结晶等可能反复出现。
- 不存在适用于所有原料药的统一“置换次数、反应温度、搅拌时间、残氧限值”。具体要求应由品种工艺研究、控制策略、适用的注册要求及经批准的工艺文件确定。[S1] §6.41、§8.30；[S2] §6
- 不能仅凭字段名称将所有参数定为关键工艺参数（CPP）。应依据参数变化对关键质量属性（CQA）的影响及研究证据确定。收率、耗时等也不自动成为 CQA。[S2] §3.1.4—§3.1.5；[S3] §3
- 无菌原料药的灭菌和无菌操作需要额外规范。Q7 覆盖至原料药被制成无菌状态之前，不足以单独支持无菌工艺的完整检查表。[S1] §1.3

## 2. 按工艺步骤梳理的通用操作矩阵

以下各项的采集频率、限值、仪器、记录方式及是否需要独立复核，均应按实际工艺明确。列出的检测项目为候选项，不表示每批、每步均需实施。

| 编号／步骤 | 通用操作 | 常见操作参数与记录 | 常见检测项目／终点 | 主要检查项目 |
|---|---|---|---|---|
| OP01 物料接收与放行 | 接收、核对、待验、取样、检验、放行 | 名称、规格、供应商、物料批号、数量、接收与取样时间、储存条件 | 身份鉴别及适用的含量、纯度、水分等 | 包装与标签正确；状态清楚；取样具有代表性；已按规定批准使用 |
| OP02 称量与分装 | 领料、称量、复核、分装 | 理论量、实际净重、皮重、单位、称量时间、衡器编号、折干／折纯计算依据 | 适用时核验浓度、含量或水分以确定折算量 | 品名批号正确；衡器适用且校准有效；数量与计算核对；防混淆和交叉污染 |
| OP03 生产准备 | 清场、设备检查、组装、管线与公用系统确认 | 设备编号、清洁完成时间、允许使用时限、检查时间、仪表状态 | 适用时清洁残留、公用介质质量、设备密闭性 | 前批物料和标签清除；设备清洁可用；管路与阀位正确；气源和仪器状态满足要求 |
| OP04 配液与溶解 | 加溶剂、配制试剂或缓冲液、搅拌溶解 | 投入量、比例、浓度、料温、转速、起止时间、配液后保存时限 | 澄清度、浓度、pH、水分，或规定的溶解终点 | 溶剂／试剂身份正确；配制顺序正确；标签与有效使用期明确 |
| OP05 气体置换与吹扫 | 置换设备空间气氛、吹扫指定管路或空间 | 气体名称与来源、对象、方式、循环次数或流量与时长、压力、起止时间 | 按方案设定的残氧、露点、目标残留气体等 | 气源及流路正确；逐次循环有效或连续吹扫完成；终点证据符合方案 |
| OP06 气体保护 | 建立、维持或恢复规定的保护气氛 | 气体种类、保护对象与时段、压力或流量（按模式）、中断及恢复时间 | 按风险需要监测气相残氧、湿度／露点等 | 投料、反应、取样、转移等要求保护的时段得到覆盖；开口和失压事件得到评估 |
| OP07 投料与转移 | 固体投料、液体加入、滴加、泵送、转料、冲线 | 投入顺序、实际量、浓度、起止时间、速率、料温、压力、冲洗量、来源及接收设备 | 适用时温度响应、物料平衡、浓度 | 物料／设备／管线正确；加料前提满足；保护状态维持；转移与冲洗去向可追溯 |
| OP08 升温、降温与保温 | 加热、冷却、回流、达到条件后保温 | 物料温度、夹套温度、目标范围、升降温速率、达温时刻、保温起止 | 指定测点温度、适用的回流或沸腾状态 | 不混用料温和夹套温度；计时起点正确；温度偏离有记录与处理 |
| OP09 搅拌与均质 | 溶解搅拌、反应搅拌、悬浮、混合、均质 | 设备／桨型、转速、起止时间、暂停时间、料量，适用时功率或扭矩 | 均匀性、悬浮状态、规定的物理终点 | 实际运转与设置一致；停机和异常记录完整；放大后混合能力有依据 |
| OP10 鼓泡与气液反应 | 液下通气、脱气、按工艺引入反应气体 | 气体身份、通气位置、起止时间、累计有效通气时间、流量／累计量、温压、转速 | 按目的选溶解氧、气体消耗或反应物残留等 | 气体确实进入规定位置；无未经评估的中断／堵塞／倒吸；终点按具体工艺判定 |
| OP11 反应与保温反应 | 反应、熟化反应、过程监测、终点确认 | 计时触发事件、起止与实际用时、温度、压力、转速、加料或通气条件、异常事件 | 起始物料／中间体残留、目标物、杂质、转化相关指标 | 时间及条件满足要求；取样与终点确认可追溯；规定的继续加工条件满足 |
| OP12 淬灭、中和与调 pH | 终止反应、加入淬灭剂、酸碱调节 | 试剂身份、量与浓度、加料速率、温度、时间、pH 变化 | 指定条件下的 pH、反应性物料残留或其他终点 | 顺序与温度控制正确；pH 测量条件适用；过程调整在批准范围内 |
| OP13 萃取、洗涤与分层 | 混合萃取、静置、分相、水洗、溶剂洗 | 溶剂身份和量、相比、温度、转速、混合及静置时间、次数、各相重量／体积 | pH、杂质去除、目标物在各相的分布，适用时含水量 | 保留相和弃相识别正确；乳化或分层异常处理；相标签和去向完整 |
| OP14 浓缩、蒸馏与溶剂置换 | 常压／减压浓缩、蒸馏、补溶剂再浓缩 | 料温、蒸气温度、压力与参照、时长、蒸出量、补液量、循环次数 | 剩余体积／质量、浓度、水分、目标溶剂组成或残留 | 终点有规定依据；避免无依据地仅按时间判定；接收容器和回收溶剂状态明确 |
| OP15 脱色与吸附 | 加吸附剂、接触搅拌、过滤去除 | 吸附剂批号与用量、温度、转速、接触时间、冲洗量 | 色度、杂质、吸附剂去除情况，按工艺选用 | 吸附剂适用；接触条件满足要求；过滤与物料损失情况有记录 |
| OP16 色谱纯化（适用时） | 装柱／平衡、上样、洗涤、洗脱、分段收集、合并 | 柱与介质身份、载量、流速、压力、溶剂组成／梯度、pH、温度、时间、馏分编号 | 色谱响应、馏分纯度、杂质、含量 | 柱状态满足要求；收集窗口正确；合并依据可追溯；各馏分去向明确 |
| OP17 成盐与结晶 | 加盐形成试剂、加晶种、降温、加入反溶剂 | 投入量／比例、晶种批号与量、加料速率、温度及速率、转速、起止时间 | 适用的 pH、晶型、粒度、母液含量、结晶状态 | 晶种与溶剂正确；加料／降温顺序和条件正确；异常析出有记录 |
| OP18 养晶、老化与打浆 | 保温养晶、悬浮老化、溶剂打浆 | 温度、时间、转速、溶剂量、固液比 | 纯度、晶型、粒度，或规定的过程终点 | 该步骤与前后反应／搅拌时段明确区分；待料与实际处理时间分别记录 |
| OP19 过滤与离心 | 固液分离、抽滤、压滤、离心、甩干 | 过滤介质、面积或设备、压差、转速、温度、时间、湿品量、批内分次身份 | 滤液澄清度、湿品相关指标，按工艺选用 | 滤材与组装正确；滤饼和母液身份及去向正确；分次操作可追溯 |
| OP20 滤饼洗涤 | 淋洗、浸洗、再浆洗涤、再次分离 | 洗液身份、量、温度、次数、接触与排液时间、压力／转速 | 洗液杂质、pH、电导率、目标残留等，须有适用方法 | 洗涤方式和次数符合要求；不能将洗液外观正常直接当作所有杂质已去除 |
| OP21 干燥 | 真空／热风／其他适用方式干燥、取样、终点确认 | 产品温度、加热介质温度、压力、气体流量、载量、起止、翻料／搅拌及暂停 | 水分、干燥失重、残留溶剂，适用时晶型或降解杂质 | 取样具有代表性；时长和产品温度可追溯；干燥终点满足规定指标 |
| OP22 粉碎、过筛与混合 | 粉碎、微粉化、筛分、符合规定的批内或批间混合 | 设备转速、进料速率、气压、筛网规格、时间、产品温度、输入输出量 | 粒度分布、混合均匀性及适用的物理属性 | 筛网／设备完整；批次来源和混合记录完整；不得通过混合稀释不合格批次使其达标 |
| OP23 包装、标识与储存 | 分装、保护性充气（适用时）、密封、贴签、入库 | 包材批号、皮重／净重、件数、包装起止、暴露时间、温湿度、储存及复验要求 | 净装量、密封或包装顶空气氛等，按产品要求 | 包材与标签正确；批号及状态一致；包装保护措施完成；温度偏离得到处理 |
| OP24 清洁与换批 | 排空、清洗、冲洗、拆洗／在线清洗、干燥、检查 | 清洁剂身份与浓度、温度、接触／循环时间、流量、冲洗量、脏设备及清洁后保持时间 | 产品／清洁剂残留、适用的微生物、TOC／电导率等 | 清洁程序适用；难清洁部位及取样点覆盖；目检与分析各自满足要求 |
| OP25 检验、审核与批次处置 | 成品取样、QC 检验、批记录审核、批准／拒绝、留样、稳定性考察 | 样品身份、方法／标准版本、检测与审核时间、结果、偏差关联、留样条件 | 鉴别、含量、杂质及产品适用的其他质量指标 | 记录完整；检验有效；异常已按程序处理；质量部门按职责完成批次处置 |

对应监管依据：生产指令和批记录见 [S1] §6.4—§6.7；物料管理见 §7；生产和过程控制见 §8；包装储存见 §9—§10；实验室控制见 §11；清洁验证见 §12.7。具体字段依据工艺选定；禁止利用混合使不合格批次达标见 §8.41。

## 3. 气体相关操作：置换、吹扫、保护、鼓泡分别管理

### 3.1 操作含义与最小记录

现场术语可能重叠，英文 purge 也可能对应“置换”或“吹扫”。应同时依据操作目的、作用对象、通气位置与执行方式解释，保留原文术语。

| 操作 | 主要目的与对象 | 重点记录 | 不能单独据以认定合格的证据 |
|---|---|---|---|
| 气体置换 | 改变设备、容器或管线内部原有气氛 | 气体身份；置换对象；连续流通或循环方式；有效循环次数及每次条件，或流量／时间；方案要求的终点 | 只写“置换若干次”，未说明实际方式、循环是否完成或其他规定条件 |
| 气体吹扫 | 使气流通过指定管路、空间或部位以清除规定对象 | 吹扫起点与终点；气体；流路；流量或压力；起止及有效时长；规定的终点 | 只写“开气阀”或“吹扫完成”，不能证明指定流路及终点满足要求 |
| 气体保护 | 在指定时段维持物料周围的受控气氛 | 保护对象；气体；静态密闭或动态供气方式；覆盖时段；规定的监测值；中断、开口和恢复事件 | 反应前置换完成，不能证明后续反应、取样和转移时始终满足保护要求 |
| 气体鼓泡 | 将气体通入液相，用于脱气、传质或反应 | 通气点位；气体；气体用途；液量；流量；温压；转速；起止与中断；过程终点 | 顶空通气不等于液下鼓泡；出现气泡不等于脱气或反应终点已达标 |
| 包装充气／气体顶替 | 建立包装内所需气氛或辅助物料转移 | 包装／转移对象；气体；方法；起止；压力或流量；适用的顶空检测 | 同一气体在反应釜使用合格，不能直接证明包装步骤已完成或适用 |

### 3.2 建议的气体检查项

| 检查项 | 需要的证据或记录 | 适用说明 |
|---|---|---|
| 气体身份与用途匹配 | 气体名称、规格、供气来源与标识、批准的用途 | 氮气、氩气不能在无依据时互换；氢气等反应气体不能当作惰性保护气；二氧化碳也不对所有体系惰性 |
| 气源与供气系统适用 | 质量证明、供应或生成系统状态、规定的确认和监测记录 | 影响产品质量的气体公用系统应确认并适当监测；不能只看气瓶是否有气。[S1] §4.20 |
| 使用点气体质量符合用途 | 按风险确定的纯度、氧、水／露点、油、颗粒或微生物等指标 | 不是所有场景都检测全部项目，也不是所有工艺气体都要求无菌过滤 |
| 管路、连接与排出路径正确 | 设备／接口身份、阀位、流路、密闭性及适用的过滤器状态 | 总管供气正常不等于目标设备或液下分布器得到正确供气 |
| 置换／吹扫执行符合方案 | 逐次循环，或连续流通的流量、起止与中断记录 | 有效循环的定义必须来自该方案；次数达到要求仍须核对其他规定条件 |
| 规定终点满足要求 | 测点、时间、方法、仪表、实测值、接受准则及版本 | 残氧、露点等并非对所有操作都必须逐批检测；经论证的控制方式应清楚且可执行 |
| 保护时段完整 | 指定操作的开始／结束及其间要求的状态记录 | 重点关注投料开口、取样、转移、停机、重新连接与恢复 |
| 中断与异常已处理 | 失压、流量异常、堵塞、开口、供气切换等事件及处置 | 静态密闭保护不一定要求持续流量，不能把“流量为零”一律判为保护失效 |

压力、温度及其他安全联锁可能同时服务于工艺安全和产品质量，应分别记录其依据及判定。本文不提供氢气等危险气体的通用操作设定值。

## 4. 通用参数字典与记录口径

### 4.1 用户所列时间字段的区分

| 原文表述 | 建议解释或拆分 | 必须补足的上下文 |
|---|---|---|
| 反应时间／反应用时 | 规定反应时长；实际反应持续时间；必要时有效反应时间 | 是要求还是实际值；从投料完成、达温还是其他事件开始；是否扣除暂停 |
| 反应温度 | 规定的温度范围；实际物料温度观察序列／记录 | 物料、测点、单位；不将夹套、热媒、蒸气温度直接当成料温 |
| XX 气置换次数 | 规定循环次数；逐次执行；实际有效完成次数 | 气体、设备／空间、方式；什么算一次完整循环 |
| XX 气鼓泡起止时间 | 鼓泡开始、结束、暂停、恢复等事件 | 通气对象和位置；日期；气体；气体流量；跨日与中断处理 |
| 搅拌时间 | 指定目的和步骤下的搅拌时段及累计时间 | 溶解、反应、洗涤、结晶、取样前混匀等不能混并为同一个时长 |
| 保温时间 | 满足规定起算条件后的保温时段 | 计时触发与结束条件；温度偏离后的计时处理应由规程定义 |
| 反应终点时间 | 根据规定终点确认完成的相关时间 | 区分取样时间、检测完成时间、结果批准时间及实际转入下一步时间 |
| 等待／保持时间 | 两个明确定义事件之间的储存或等待时长 | 等待位置、物料状态、温度、气氛；不要自动计入有效处理时间 |

起止时间宜包含完整日期和统一时区或当地时间约定；原始记录中的精度也应保留。若只有“上午”“约两小时”等模糊表达，不应补造成精确时间。

计算建议：

- 自然经过时间 = 结束时间 − 开始时间，前提是两个事件确属同一次操作且时间信息完整。
- 多段操作的累计运行时间 = 各有效运行时段之和，处理重叠时段并避免重复计数。
- “有效反应／有效保温时间”是否扣除温度偏离、搅拌停机或通气中断，由批准的计时规则决定；不得自行扣除，也不得自动把日历时长当作有效时长。
- 有过程终点的步骤，应区分“满足时间条件”和“终点检验达标”。Q7 §8.20 指出，pH 调整、氢化、干燥至规定指标等步骤可能依靠取样检验确定完成，单纯时间限值未必适合；既定时间限制仍须遵守或记录并评价偏差。[S1]

### 4.2 数量、条件与检测字段

| 参数族 | 候选字段 | 常见单位／记录方式 | 解释要点 |
|---|---|---|---|
| 温度 | 料温、夹套温度、进出口温度、蒸气温度、环境温度、升降温速率 | ℃；℃/min；观察序列 | 记录对象、测点、范围和偏离事件；设定值与实测值分开 |
| 压力 | 容器压力、供气压力、过滤压差、真空条件 | kPa、MPa、mbar 等 | 明确绝压、表压、压差；“真空度”原文含义不明时保留未决 |
| 时间 | 起止、持续、累计、允许保持、超限持续 | 时间戳；s、min、h | 区分要求、原始事件和计算值；保留计算依据 |
| 次数 | 置换、洗涤、萃取、冲洗、循环次数 | 整数／次 | 次数与循环定义关联，记录部分完成和重做 |
| 搅拌／旋转 | 设定及实际转速、桨型、搅拌方式、离心转速 | rpm、r/min；必要时相对离心力 | 转速不能跨设备直接代表相同混合或离心效果 |
| 流量与加料 | 气体流量、液体流量、滴加速率、进料速率、累计通入量 | L/min、kg/h、mL/min、标准体积等 | 标准气体体积须说明参照温压；气体身份和测量点不可缺失 |
| 物料投入 | 质量、体积、浓度、摩尔当量、比例、载量 | g、kg、mL、L、mol、eq、% | 明确质量／体积基准、折干折纯依据、实际物料批号 |
| 酸碱与离子相关 | pH、电导率、适用的氧化还原电位 | pH 值、µS/cm、mV | pH 无量纲；记录取样和测量条件；非水体系需适用方法 |
| 气氛与湿度 | 气相氧、溶解氧、露点、相对湿度、目标气体残留 | %、ppm、mg/L、℃露点、%RH 等 | 气相氧与溶解氧是不同指标；ppm 的体积／质量基准应明确 |
| 反应与纯度 | 起始物料残留、目标物含量、单杂、总杂、手性杂质 | %、mg/g 等，按方法定义 | HPLC 面积百分比不自动等于质量百分含量、收率或转化率 |
| 水与挥发物 | 卡尔费休水分、干燥失重、具体残留溶剂 | %、ppm、mg/kg | 三者含义不同；干燥失重不等于专属性水分或某一种溶剂残留 |
| 固体性质 | 晶型、粒度分布、D10／D50／D90、堆密度等 | 类别、µm、g/mL 等 | 需记录方法及粒度统计基准；是否纳入控制取决于产品用途 |
| 外观与物理终点 | 色泽、澄清度、分层状态、可见异物、溶解情况 | 受控描述及观察结果 | “澄清”“无可见异物”只能支持其对应项目，不能证明化学纯度 |
| 微生物相关 | 生物负载、特定微生物、内毒素等 | 按检测项目和方法 | 依据产品与工艺适用性选择，不将无菌、微生物限度和内毒素互相替代 |
| 清洁相关 | 具体产品残留、清洁剂残留、TOC、电导率、目检 | µg/取样面积、浓度、受控描述等 | 间接指标的适用性和残留限度需论证；目检不能代替全部清洁证据 |
| 过程表现 | 实际收率、理论收率、质量平衡、物料损耗 | %、质量／数量 | 明确分母和计算基准；不与含量、纯度混用 |

质量标准本身应包含检验项目、方法及接受准则。Q6A 将性状、鉴别、含量和杂质列为新化学原料药普遍适用的检验类别，粒度、晶型、水分等按需要设置。[S4] §3.1—§3.3.1

## 5. 取样过程控制：分别判定程序、样品、检验和继续加工条件

### 5.1 建议的检查表

| 阶段 | 检查项目 | 应关联的记录或证据 | 不满足／信息不足时的处理原则 |
|---|---|---|---|
| 取样前 | 取样方案和方法适用且版本正确 | 产品、批次、步骤、方案／规程版本、取样目的 | 未明确适用依据时不能直接判定符合要求 |
| 取样前 | 人员具备相应资格 | 人员身份、相关培训／授权状态 | 按程序评估资格缺口及影响 |
| 取样前 | 取样时点或触发条件正确 | 反应阶段、达温／混匀状态、规定的取样时间或事件 | 不能把提前或不同阶段样品的结果套给目标终点 |
| 取样前 | 取样对象与位置正确 | 物料批号、设备、相别、层位、取样口 | 特别核对有机／水相、滤液／滤饼、上中下层等身份 |
| 取样前 | 数量、位置及混合规则有代表性依据 | 取样点、样本数、单点量、混合样方案 | 不能统一套用某个容器取样公式或“取一瓶即可” |
| 取样前 | 工具、容器与取样点状态符合要求 | 清洁、干燥、材质、必要的无菌或防吸附条件 | 无菌要求按用途确定；清洁状态与样品相容性分别评估 |
| 取样中 | 保护及防污染措施符合要求 | 密闭／开口方式、气体保护、暴露时间、环境或个人防护要求 | 取样后结果正常不自动消除取样污染或气氛破坏风险 |
| 取样中 | 取样具体方法得到执行 | 规定的混匀、取样路径、体积／质量及必要的取样口预处理 | 冲洗、弃初样和多点取样等均按适用方案，不能无条件套用 |
| 取样中 | 即时处理保持了样品代表的状态 | 取样至淬灭／稀释／固定的间隔、方法、容器与试剂 | 继续反应、吸湿、挥发或氧化可能使样品不再代表取样时状态 |
| 取样后 | 样品身份完整 | 唯一样品号、产品／物料、批号、工序、点位、时间、取样人 | 身份无法确认的样品不能直接关联批次或步骤判定 |
| 取样后 | 包装、保存和运输适用 | 密封、避光、温度、气氛、保存时限、交接与接收状态 | 超时／超温等按样品稳定性及程序评估，不直接删弃原记录 |
| 取样后 | 原容器或工艺设备状态恢复 | 关闭、密封、标识、保护恢复和必要的状态检查 | 取样合格与设备恢复合格分别确认 |
| 检验 | 方法、设备与分析运行有效 | 方法版本、仪器状态、适用的系统适用性、原始数据与计算 | 分析无效、技术失败和检测超出接受准则应分别记录 |
| 检验 | 检测结果满足适用准则 | 项目、数值／定性结果、单位、准则版本、复核 | 检测待完成或缺少结果时标记待判定，不预填合格 |
| 后续操作 | 规定的继续加工条件满足 | 结果确认、适用授权／批准、下一步实际开始时间 | 若工艺设有结果等待点，应核对放行或批准发生在继续操作之前 |

Q7 要求科学合理的过程取样方案，防止取样造成污染，并保持样品收集后的完整性。[S1] §8.34—§8.35。来料取样的代表性要求见 §7.33—§7.35。上述具体字段是落实这些原则的建议。

### 5.2 不宜用一个“是否合格”承载所有状态

建议至少分开记录：

1. **执行状态**：未开始、进行中、已完成、已中断等。
2. **取样程序符合性**：符合、不符合、待判定、不适用及依据。
3. **样品适用性**：可用于该检测、需评估、不能用于该检测及依据。
4. **分析运行状态**：未检验、进行中、有效、无效或技术失败。
5. **项目结果判定**：符合接受准则、不符合、未决／待结果、不适用。
6. **步骤或批次处置**：允许继续、待审核、按批准程序调整、拒绝等，保留决策人和依据。

这些是建议的数据维度，不是 ICH 规定的系统枚举。若原文仅写“过程控制合格”，应保留其原始结论和所指对象，不能自动补出所有子项均已检查合格。

取样出现偏差但检测数值达标，不代表取样程序达标；检验结果是否仍可用，应结合偏差影响评价。未检出也应结合方法、检出限／定量限与表达方式解释，不自动等于“含量为零”。

### 5.3 过程调整与 OOS 的边界

过程检测至少要区分“指导过程监测／调整”和“判定指定终点或质量标准”。例如，尚在允许反应阶段的中间取样提示继续反应，与已宣布完成的终点样品不符合要求，含义不同。

Q7 §8.33 允许合格人员在质量部门预先批准的限度内实施过程调整，并要求完整记录；§8.36 指出，仅用于监测和／或调整过程的过程检验通常不需要 OOS 调查。该条不能扩展为所有 IPC 不符合均无需调查，也不能成为隐去失败结果、无依据重复检测或超范围调整的理由。应按检验目的、适用标准及企业程序决定偏差／OOS／其他调查路径。[S1]

## 6. 如何建立每个项目的合格判定依据

| 判定对象 | 应有的依据 | 典型证据 | 常见错误 |
|---|---|---|---|
| 工艺参数符合性 | 适用于该产品、工艺版本、步骤和规模的范围／条件及计时规则 | 原始过程记录、仪表数据、偏离时段 | 将设定值作为实际值；用平均值掩盖超限；不同测点混用 |
| 气体操作符合性 | 气体及用途、执行方式、规定的循环／时间／终点、保护时段 | 执行记录、规定的监测、异常与恢复记录 | 用一次置换证明全程保护；将任意通气记为鼓泡 |
| 取样程序符合性 | 经批准且科学合理的取样方案与保持样品完整性的要求 | 时点、点位、工具、数量、保存与交接记录 | 只依据检验数值判断取样过程合格 |
| IPC 结果符合性 | 项目、方法、接受准则、适用的结果有效性和复核要求 | 对应样品的原始数据、检测值、方法版本、审核 | 将色谱面积百分比直接解释为含量；混用中间样与终点样 |
| 步骤完成 | 该步骤规定的全部完成条件及必要的进入下一步条件 | 相关操作、参数、IPC 和授权记录 | 只要时间到了或表单打勾就认为完成 |
| 批次批准／放行 | 适用质量标准、批记录审核、偏差及调查处理、授权职责 | 质量批准记录及关联证据 | 把单个样品合格或算法检查通过当作批次放行 |

落地时，应逐项确定：适用条件、要求来源及版本、测量／检查方法、接受准则、记录频率、责任人、必要复核和失败处置。检查频率可包括连续监测、定时记录、事件触发、每次操作或按经论证的计划执行，不应默认全部连续监测或全部只在结束时打勾。

接受准则必须在结果判定前明确。只有目标值、没有允许范围或终点定义时，不应自行补出合格限值；文件之间要求冲突时，应确认适用版本和权限，不能自行选择更宽松者。

## 7. 用于批记录或文档抽取时的建议结构

以下只是调研层面的候选结构，不表示现有系统或本体已具有这些实体和关系。

建议以“**批次 → 工艺步骤实例 → 操作实例 → 参数记录／检查／样品 → 检验结果 → 判定与处置**”关联记录，并保持要求与实际执行分开。

| 记录对象 | 建议保留的核心信息 |
|---|---|
| 工艺要求 | 产品／路线、版本、步骤、适用规模／设备条件、参数或检查项、接受准则、条件和来源 |
| 实际操作 | 批次、步骤实例、操作名称与目的、物料及设备、执行人、起止／中断、原始记录位置 |
| 参数观察 | 关联操作、参数名、观察对象与测点、值、单位、时间、来源仪器／方法、原始值或计算值 |
| 操作检查 | 对应要求、被检查对象、实际观察、执行状态、符合性结论、检查人与时间 |
| 样品 | 唯一样品身份、来源批次与步骤、物料／相别／层位、取样时间、取样及保存条件、交接关系 |
| 检验 | 样品、项目、方法和版本、原始数据、结果及单位、分析有效性、接受准则、复核 |
| 判定与处置 | 判定对象、依据版本、支持证据、结论、权限与人员、时间、偏差／调查关联 |
| 文档证据 | 文件身份和版本、页码／表格／单元格或文本位置、原文、要求／实际／条件／否定的语义 |

优先建立的操作候选词：

> 清场、称量、复核、投料、滴加、转料、冲线、配液、溶解、升温、降温、保温、回流、搅拌、置换、吹扫、保护、鼓泡、通气、脱气、反应、淬灭、中和、调 pH、萃取、静置、分层、水洗、浓缩、蒸馏、溶剂置换、脱色、吸附、色谱、成盐、加晶种、结晶、养晶、打浆、过滤、离心、洗涤、干燥、粉碎、过筛、混合、取样、检验、包装、储存、清洁、审核、放行。

词表只用于识别候选。规范化需依据上下文：

- “氮气保护下搅拌”表达气氛要求或实际状态与搅拌的关系；“保护”并非“搅拌”的同义词。
- “反应前置换”与“反应中保护”应分开，且要识别“前／中”等时序。
- “溶剂置换”通常是物料处理，不等于气氛置换。
- “氮气吹干”可能是样品前处理、设备干燥或生产操作，应先识别对象。
- “搅拌至溶清”包含操作及终止条件，没有给出可直接填入的固定时长。
- “必要时取样”“若不符合则继续反应”属于条件要求，不能记为已实际取样或实际检验不合格。
- “未进行”“未记录”“记录未找到”“不适用”“待检”“检验不符合”表达不同状态，不能相互替换。
- 原始气体名称未明确时保留“气体待确认”，不能把“惰性气体”自动补为氮气。
- 表格中的空白、斜线、勾选和合并单元格需结合表头及记录约定解释，不能把空白直接当成合格或不适用。
- 同一批次不同步骤的温度、样品、搅拌时间应按步骤实例绑定；同名字段或相邻文本不足以证明归属。

## 8. 发酵／生物原料药的扩展项

若企业业务包含发酵或生物原料药，应在通用矩阵基础上增加以下模块。具体产品范围还需核对相应生物制品及无菌要求；本节不是完整生物工艺指南。[S1] §18

| 模块 | 特有操作与记录 | 常见过程检查或检测 |
|---|---|---|
| 种子／细胞库及接种 | 库身份、传代／代次、复苏、扩增、接种量、接种起止、培养基与补料批号 | 身份、纯度、适用的活率／生长与污染监测 |
| 培养／发酵 | 温度、pH、溶解氧、搅拌、空气／氧／二氧化碳等气体流量、罐压、补料、泡沫与消泡操作 | 生长、活率（适用时）、代谢指标、产率、污染；通气目的不同于小分子惰性保护 |
| 收获与澄清 | 收获时间、温度、离心／过滤条件、中间液保持条件 | 目标物回收、澄清效果、生物负载等 |
| 纯化与浓缩换液 | 色谱载量及收集、膜规格、跨膜压、流量、温度、pH、电导率、置换体积、保持时间 | 纯度、聚集体、过程相关杂质、适用的效价等 |
| 病毒去除／灭活（适用时） | 经产品和步骤论证的条件、时间、载量及关键控制 | 经验证的步骤执行条件及相应质量控制；不能直接套用通用时间／温度 |
| 清洁、消毒、灭菌与无菌操作（适用时） | 具体循环、介质、温度、压力、时间及设备状态 | 按具体法规及验证方案执行，不能用气体吹扫代替灭菌或无菌保障 |
