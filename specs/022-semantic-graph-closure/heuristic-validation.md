# HRS-5592 启发式优先识别的本机验证

日期：2026-09-10。状态：1次冻结本机实验已结束；48任务预算耗尽，全文识别未完成，未部署。

**实测结论：启发式准入在0.59秒内启动首任务，但48次任务仍用20分44秒，最终没有
有效属性。主要成本来自重复的发现/核验；准确挂接还受实体拆分、字面量协议和主体引用约束影响。**
系统有效边7条不能等同7条业务正确关系，具体诊断见第3节。

本次使用用户指定Word原件、当前CMCReport及可达本体菜单、本机Qwen模型，验证
“先启发式定位，结果为空或不足时扩搜”的共享核心实验实现。识别结果与独立业务核对
分开记录；通过证明门不自动代表实体名称、类型及归属正确。

## 3. 独立业务核对

依据[独立原文与本体诊断](heuristic-independent-review.md)，识别外核对实际候选。
该参考不是专家批准金标；本轮不报告全文precision/recall。

首批在约69.82秒形成3条系统有效`describes`关系。其中“HRS-5592项目”可作当前
菜单下的产品提及，但“属于肿瘤药产品”和“目前项目处于I期临床阶段”是同一产品的
分类/阶段叙述，不是两个新的产品名称。前者还被分为`CytotoxicDrug`，与原文
“是否存在细胞毒性：否”冲突。发现与独立核验均放行这些候选，因此问题发生在模型语义
判定及其输入证据范围，不能只归因于图谱展示或检索速度。

同时保留两项输入契约限制：原文明确为原料药，而当前`describes` range仅为定义成
成品制剂的`DrugProduct`；原文前后分子式、分子量存在不同值及不同角色，不能将
首次命中当全文唯一属性。没有为本次实验修改本体、原文或提示来掩盖这些问题。

最终另有3条存放要求片段，全部来自T6R1的SM5592-A14：温度/密封条件、包装和
复测期。当前StorageCondition定义允许这些内容，不能一概判类型非法；但程序未
建立A14属主，未将storageTemperature、packagingType、shelfLife挂为相应属性，
不能把这些片段当成3个完整方案，更不能套到HRS-5592成品。
包装及复测期的类型证明还引用了温度列表头，存在列角色混淆。
因此7条边的独立分类为：1条有类型契约限制的产品提及、2条明确错误产品拆分、
1条路线标题定位、3条未完成属主/字段组合的存放要求片段；不报告全文precision。

### 3.1 明确属性已有证据，仍未挂接

| 任务批次 | 已进入上下文的内容 | 实际阻断点 |
|---|---|---|
| 0007：产品的registrationCategory | P25同句中的“申报注册分类为化1类新药” | 主体、谓词、桥接均获模型支持，但role/type未决，最终field_role未决；值边界还保留了整句而非仅“化1类新药” |
| 0008：错误拆分主体的registrationCategory | 同一明确注册分类句 | 核验要求字符串对应allowed_object_classes；该字段是xsd:string，合法对象实体类列表为空本属正常；主体本身也有拆分错误 |
| 0016：产品的appearance | P36“类白色固体”；上下文还包含P33“项目名称：HRS-5592”及P25 | 模型以“外观描述，无独立对象指称”令type/role未决，又未将P33放入subject_support，程序local_coreference未决 |

但上述拒绝没有引用相关反证，不能将它们解释成系统已正确完成全文冲突检查。

系统在481.55秒通过该关系，可作为章节定位结果；未证明完整路线整体或步骤集合，
不能据此宣称路线—步骤多跳识别完成。

### 3.2 启发式召回仍有可定位的规则缺口

冻结策略的只读重算结果：根层H0完整候选121个、H1候选396个，合计517个
主体—谓词—记录组合；它们仍不是已执行任务。初始实际准入只有51个组合。

- 清洗关系的本体标签是“含清洗方法”，规则只保留整词，登记别名需要完全匹配才能
  展开；“含清洗方法”无法触发“清洗方法/清洁方法”变体。原文实际有“设备清洗方法”
  章节及11行清洗表。故H0/H1为0是查询词形问题，H2随后承担了可用词面检索完成的工作。
- 共线关系中的短词`F4`按无边界子串命中32条，29条属于分子式等嵌入片段。
  再将相关整表加入H1后，该槽位H1扩大到175条，其中143条没有自身词面命中。
- 产品关系的宽泛字段“规格”出现在84条上下文中，引入设备/物料语境；
  清洗残留物的“残留物”还会匹配工艺中的“残留物料”，需要保持角色核验。

仅在诊断查询副本中剥离“含”，已有规则便能定位11行清洗表及一处“清洁方法暂未明确”
限定表述。该结果没有反馈给运行，不能据此宣称真实H2耗时已经省掉。
下一版应优先验证关系助词与核心词拆分、ASCII短词边界、限定词/反证召回，以及
“上下文补全”和“将整表每行变成识别任务”的分离；不得通过裁掉完整覆盖分母提速。
