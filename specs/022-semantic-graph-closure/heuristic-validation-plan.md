# HRS-5592 启发式优先图谱识别验证预登记

日期：2026-09-10。状态：保留运行前实验协议；本轮实际执行及结果见
[启发式验证记录](heuristic-validation.md)，本文的预期条件不等于验收通过。

## 1. 目标、范围与依据

用户指定同一份 HRS-5592 Word 原件、`CMCReport` 及其关系图谱本体定义和本机 LLM，
验证[性能优化方案第 8 节](../../docs/关系谱图识别新内核的性能优化方案.md)的
“先启发式搜索，空命中或证据不足再扩大范围”，测量识别各关键节点的绝对耗时。

本轮在共享 `OntologyGuidedExecutor` 中提供显式开启、默认关闭的实验检索策略，
由独立评测入口冻结和调用；不在 `app.evaluation` 中复制识别算法。线上默认行为、
源文件、权威本体、历史运行和历史冻结评测不修改；不启动/重启生产服务、不部署、
不提交业务事实。新增制品、调度和模型用量记录属于本次实验写入，不能称整轮只读。

继承[021 规范](../021-ontology-guided-doc-graph/spec.md)、[022 规范](spec.md)、
[实施计划](plan.md)、[排序契约](contracts/ranking.md)与
[活动评测说明](../../backend/app/evaluation/README.md)中的原文权限、独立验证、
本体菜单、覆盖、预算、隔离和质量门。本文只登记本次诊断范围，不把整个 H01–H06
生产工作包视为已实施，也不替代公共 API、持久“继续检索”、完整增量仓储和部署验收。

只测试新策略的绝对耗时。历史 1610.79 秒、3444 机会、725315 次 SELECT 用于解释
测量动机；输入环境、预算和实现不同的运行不能直接相除后宣称提速比例。

## 3. 实验策略与必须保持的语义

| 阶段 | 本轮要观测的动作 | 进入下一步的理由 |
|---|---|---|
| H0 | 从当前本体标签/定义、字段标签、章节和表头作确定性直接定位，命中原始记录并补必要上下文 | 零命中、当前候选均不成立或存在其他来源缺口 |
| H1 | 登记同义词和词面变体、其他章节、字段组、续表和明确引用；仍不要求语义模型先运行 | 可用对象/值仍不足，表达差异或跨段证据仍未解决 |
| H2 | 按需语义检索与小池精排；不以无关尾部凑满；保留完整池提交/失败屏障 | 当前池证据不足，需处理剩余范围 |
| H3 | 从完整未检查全集中按章节/位置有界分页补查，保留游标和继续义务 | 当前目标满足、实际全集耗尽或本轮预算停止 |

首轮建议候选页 8、补页 16/32，H2 池 16 起步；具体实现支持哪些能力必须在
manifest 明示。如果实验版本未实现某阶段，只能标 `not_implemented`，不能跳过后
宣称完成整个阶梯；若某阶段可用但本次未触发，应记 `not_triggered`。

首次真实运行冻结补充：H2 batch为4、候选池不补满；已有槽位等待H2时最多先完成
8次就绪任务，再允许启动其补搜。该配额进入策略快照和指纹，保持主识别在途1。
本轮复用既有主体/关系属性轮转，未实现方案建议的4:1关键路径优先配额。

这些规则是检索准入，不是事实生成。保留单主体—单谓词—单目标记录任务，以及
真实、独立的 discovery/verification 请求。命中记录、相似度、摘要、表头和文件名
都不能直接生成合法关系。主体归属、类型、方向、实体层级、桥接、极性、条件和
反证须继续通过既有证明门；不得为获得非空图放宽断言。

H0/H1 不依赖尚未启动的语义池；一旦任务依赖 H2 排序，必须等相应池完整提交。
已生效对象才有属性任务。宽泛 `describes` 的失败不得长期占用全部机会，根关系、
已到达子主体和属性按冻结规则轮转；保留所有槽位的首派发时间、最长等待和次数。

“没有候选”与“技术失败”分开：无命中/明确拒绝推进不同记录或新上下文；超时、
协议失败、不可用和上下文超限按技术状态处理。相同输入不反复重试直到得到肯定。
一个清单有多页时不能找到首条就声明完整；必要表头、主体与反证不能被 Top-K 裁剪。

每个已到达主体—谓词保留完整记录全集 U，H 阶段与原有 phase1/phase2 分开记录。
覆盖满足 `planned = unattempted + attempted_incomplete + examined`；关键词检索、
候选准入、向量计算或读取背景不直接增加 examined。剩余范围和未展开前沿始终可见。

## 4. 预算与停止

为避免无界占用本机模型，首轮建议最多 48 次任务派发、96 次主模型请求、1800 秒
识别壁钟时间，主识别在途 1；总请求包括技术重试及独立核验。实际可执行限额由主
实验入口在首次调用前确认并写入 manifest；本文建议值不假冒现有配置已经支持。
token 上限沿用实际本机配置并冻结数值，不以平均估算替代精确预扣。

时间限额是协作截止：到期停止新派发，记录合法边界上的停止时间，以及已在途请求
造成的尾部时间。设置并记录单次请求超时，截止不能靠硬杀后丢失费用和结果。
若适配器只能支持更小任务/时间/请求限额，必须在运行前显式冻结实际值；实际调用
数和缺测费用照实报告，不能假称已执行不存在的总请求硬门。

预算停止、技术暂停或仅阶段结束都记 `completion=incomplete`，关键节点未达不能
计为 0 秒。仅当共享核心的完整覆盖及前沿收尾条件满足时才可讨论全文处理完成耗时。
本轮诊断不足不自动延长预算；若需要新一轮，应创建新身份并保留该轮全部结果。

## 5. 关键节点与计时口径

使用单调时钟测持续时间，UTC 记录事件时间。`T0` 是本轮识别开始；输入冻结、
DOCX 解析、本体加载和策略索引构建另列前置耗时，并同时提供包含前置阶段的总耗时。
每个节点保留候选首次出现、独立核验结束、有效图提交和独立诊断核对结果，不能
把“模型返回 supported”或“引用可回放”当作该业务节点已经正确完成。

| 关键节点 | 达成条件及输出 |
|---|---|
| 原文/本体/索引就绪 | 真实解析、完整本体菜单和共享检索索引已构建；各步骤单独计时 |
| 首批启发式定位 | 首次有序候选和完整上下文可用；保存槽位、记录、词项来源和 H 阶段 |
| 首条有效关系 | 共享证明门当前版本合格并进入有效肯定图；输出谓词、对象、记录和时间，另列业务核对 |
| 产品关系 | 从 CMCReport 到文档所述产品的合法有效路径和实际名称/类型；不要求使用静态图谱的实体 ID |
| 首个有效属性 | 具有当前有效主体路径、本体属性 IRI 与双端归属证明的属性进入图；不以无 IRI 展示字段计数 |
| 产品主要属性 | `projectName`、`molecularFormula`、`molecularWeight` 分项计时和核验；无值、未调度、失败和不适用分开 |
| 合成路线 | 命名整体的合法路线实体/关系，不能用单步骤或标题直接替代；随后记录合法步骤路径的时间 |
| 清洗关系 | 实际本体允许的清洗关系及对象有原文证明；只见到清洗词语不计达成 |
| 设备/物料清单 | 首项有效时间、已取得项数、完整表格/续表边界是否处理和剩余范围；未有完整独立清单参考不宣称全集召回 |
| 关键多跳路径 | 以冻结本体定义列出的目标路径逐项核对全部有效边及末端属性；路径部分完成与完整达成分开 |
| 本轮结束 | 总壁钟、实际停止原因、在途尾部、覆盖及全部未达节点 |

诊断期望由原文和本体单独核对，在识别外使用；不用静态演示 670 项属性作为金标。
表内谓词例子不是追加本体。若原件未提供某值或本体不允许直接挂接，记录具体缺口，
不把预登记目标当作必须生成的事实。

## 6. 阶段成本、可回放制品与工程验证

按槽位、任务、H 阶段及模型请求 ID 汇总以下实测；所有失败和未完成调用保留：

- 词面索引/搜索、上下文装配、embedding、rerank、discovery、verification 和证明门耗时。
- 调度排队、模型服务壁钟、请求与响应 token、已知实耗、预扣、重试和未知费用。
- 持久化次数、耗时、逻辑/实际字节、SQL 语句数与类型；未接真实数据库的路径标

计时可以嵌套或重叠，各阶段累计值不能简单相加当总壁钟。只有一次运行时提供实际

调用日志、检索阶段轨迹、公共图/覆盖、阶段计时与关键节点表、诊断核对及最终状态。

技术失败不变成语义空结果；预算停止仍保留未知与未查范围；默认策略回归和共享核心
