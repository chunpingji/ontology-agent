# 分层识别与属性专家审核闭环
2026-09-13 用户授权实现：逐层识别 → 属性有效绑定后停止普通扩搜 → 关系与下一跳 → 专家审核 → 按理由局部重识别。

## 需求与澄清
1. 新运行按主体最短跳数逐层推进，同层先属性再关系；下一层只登记待展开主体，不提前穷举谓词或消耗排序/识别请求；同层公平轮转。
2. 已有效绑定原文值排除出同主体版本、谓词、适用范围的普通重复候选；保留原文对其他属性、主体的用途。
3. 首版对无条件、约束已解决的最多一个值属性提供关闭，须完整证明、无未解决技术失败/反证且完成有回执的冲突检查。多值及没有明确上限的未指定属性只去重。
4. 关闭不把未检查来源记作已检查；疑似冲突、反证、条件及必需补证不因普通搜索关闭丢弃，不声明全文无遗漏。
5. 首版审核目标为已识别数据属性。专家确认/驳回准确版本，驳回理由必填；确认不伪造模型通过、证明或业务事实。
6. 驳回立即退出有效投影，原文按原主体/谓词及理由回到局部候选池。属性归类错误允许在同主体其他合法属性中局部识别；不凭意见新增主体。
7. 修复复用本体快照、原文和正确结果，只重开受影响属性/来源，保留旧费用；相同错误结论不能绕过驳回自动恢复。
8. 静止运行可审核/修复；活动运行先走现有暂停边界。操作绑定运行、候选、图谱及审核版本，幂等、可审计、按拥有者隔离。
9. GET 不启动模型；旧运行保留冻结调度策略。审核通过可回放边界接入，不篡改旧检查点或静默升级本体/协议。

## 验收
层 N 未完成前不创建/排序层 N+1 谓词；冲突反例不被关闭屏蔽；理由、回池和修复结果可见；正确结果保留；覆盖旧版本、跨用户、幂等、冷恢复、迟到工作器、缓存及技术失败。
工程测试与真实质量/成本评测分开；本次不部署、不运行生产迁移或真实模型任务。
