# 显式对象候选与依赖就绪识别修复

日期：2026-09-14。依据：用户要求修复短 CMCReport 关系识别成本高、属性结果不完整的问题；实测见 [describes 分析](../../../docs/CMCReport-describes识别成本与完整性分析-20260914.md)。

## 需求与范围

- 关系检索区分对象指称与对象属性。已知类型的普通属性标签不应单独使其标量记录成为高优先级对象发现任务；名称、代码、明确关系句和多对象表格仍须保留检索机会。
- 已经获得有效肯定证明的对象应能继续识别其同源属性，不等待不相关根关系完成。复用现有主体依赖、字段绑定、优先份额、预算和暂停继续机制，不新增执行引擎或历史快照。
- 减少模型传输中的重复身份、空字段和无关协议内容，保持两次独立发现/核验、冻结断言匹配、合法类型、原文权限、主体归属、极性、条件及反证校验。
- 保留当前 −3 校准阈值。按用户澄清，CMCReport.describes 识别到 DrugProduct 即可，
  不要求原料药/制剂或子类型判定。ActivePharmaceuticalIngredient 表示活性药物成分，
  不直接等同于原料药，不纳入此关系的类型菜单；本次不修改本体 TTL。

## 新运行与恢复

新修复冻结 `source_object_recognition=source-object-recognition-v1`；执行顺序冻结为 `dependency-ready-v1`。
旧运行缺少该标记时继续原有候选、请求和分层顺序。恢复不重置任务、证明或费用，不迁移旧运行。
新模式沿用当前权威工作状态，已入队义务、失败、必要补证、反证及未展开前沿仍阻止虚假完成。
新运行另冻结 `cmc_describes_type_scope=drug-product-only-v1`；精确 CMCReport/describes
任务只保留已有合法范围中的 DrugProduct。仅收敛已解析范围，不扩大其他谓词、主体或
范围约束。模型 schema 与服务端校验一致；暂停继续保留此标记，旧协议不跨粒度复用。

DrugProduct 在本任务的识别粒度为报告所描述的药品；不以成品剂型证明或原料药/制剂
分类作为先决条件。原文名称加同源药品角色、文档描述主体的联系可以作为核验证据；
孤立项目代码、设备/工序/辅料名或报告共现不能直接通过。类型、角色与谓词判断仍独立。
项目名称/代码/编号字段仍可定位对象并证明字段关系，但不能单独充当药品类型证明；
模型类型引用菜单与服务端校验共同保留这一边界，同源药品角色正文可用于类型核验。

## 候选与属性

普通属性标签仍可定位类型相关上下文，但不作为新模式关系 H0/H1 的独立命中依据。实际原文中的对象类型、名称/代码及明确谓词仍参与检索；未在 H0/H1 入选的来源仍保留后续语义检索与有界探索机会，不获得否定或已检查状态。
同源属性优先查找应覆盖包含已证明对象锚点的完整字段组；只有真实字段标签匹配且绑定包含原始主体锚点时才获得优先。相邻表格、重复名称及不同字段组不能借此取得主体身份。
已有语义筛选工作就绪时，新策略最多等待一个普通识别任务，不再等待八次包含模型发现/核验的所谓低成本任务；评分算法、−3 阈值与已准入义务不变。
新对象仍分别发现和核验，不强制 `describes` 单值，也不因首个对象成功宣布全文完整。

## 传输

服务端保留完整目标、hash、引用和候选身份；模型传输使用可逆的任务内短引用，避免反复发送完整内部身份。只去掉不参与模型语义判断的结构字段；类型定义、来源正文、权限标记和必要证明维度仍保留。
响应 schema 可以移除展示标题、未引用定义与关系任务无关的单位字段；解码后仍交给原有领域模型和证明门。发现与核验分别校验候选/目标短引用，不允许跨任务引用、缺失、重复或目标漂移。
清洗方法说明仅在任务具有实际方法来源时发送；不把有关规则注入所有关系和属性请求。

## 验收

1. 短字段组：名称排在对象候选前列，布尔/数值属性不因目标类属性标签进入关系 H0/H1；同字段在其属性任务仍正常检索。
2. 多产品、明确关系叙述及未见字段仍可检索；没有名称不等于全文没有关系。
3. 根关系失败时，另一已证明对象仍能取得同源属性；无证明、条件性或否定关系不展开子对象，失效依赖仍撤销资格。
4. 两种策略各自冷恢复不重复已付费调用或改变覆盖；当前状态和已有旧策略回归均通过。
5. 精简请求实际缩小；短引用能够往返原身份，伪造、交换候选或越权引用失败。必要语义判断和反例测试不减少。
6. 工程测试、真实模型成本/质量与部署分别报告，不将字符缩减比例当作实测推理提速比例。
7. describes 类型菜单由 DrugProduct 及其后代收敛为 DrugProduct；不要求药品子类型，
   缺少药品角色/报告描述证据仍不得通过。其他关系与旧运行冻结策略不受影响。
