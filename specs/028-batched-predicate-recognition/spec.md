## 1. 需求与澄清

用户目标：一次模型调用能综合多个工具结果，识别和校验多个属性值，或识别同一实体的多个潜在关系，以提高整体效率。

当前实现已有多工具结果汇总和多声明核验，但任务限定一个主体、一个谓词、一个记录。本期增加不同谓词之间的批处理。

以下为本方案采用的设计判断，不冒充用户逐项确认：

- 合并同主体版本、同记录、同适用范围内已就绪的不同谓词任务；允许属性与关系混合。跨记录、跨主体和跨层级多跳不合批。
- 发现与独立核验继续分阶段；一次调用处理多项不等于取消核验。
- 每个谓词的证据权限、完成情况、反证、修复额度和语义结论独立。
- 不增加用户操作步骤，复用既有暂停、继续、调用额度和原文核验。
- 建议默认最多 4 个谓词，支持冻结为 1/2/4 对照；这是保守起点，不是已验证的最优参数。
- 首期不共享跨成员实体语义证明；共享原文传输，沿用已证明的物理身份复用规则。

## 2. 用户场景

### US-1 多属性一次处理（P1）

同一实体的一条记录包含编号、规格、数量。一次发现多个属性候选，再一次独立核验，分别保留原文和值表示。

验收：无额外取证的合成场景，3 个属性从单成员基线的 6 次发现/核验请求降至 2 次；事实、证据归属及未决项正确。此计数不作为所有真实文档的保证。

### US-2 多关系与混合任务（P1）

同一主体在一个记录中具有多个关系类型，也可能具有属性。模型一轮提出候选，关系工具同轮批量检查，随后综合结果独立核验。

验收：每条关系都有主体、谓词、对象、方向及条件证明；单条失败不影响独立事实。同一物理提及按既有身份规则复用节点，成员证明分别保存。

### US-3 缺项与部分完成（P1）

批次包含四个任务，模型只完整回答三个，或其中一个缺证。

验收：充分支持的项目正常交付；漏答、技术失败、未决与拒绝分别表达，不把遗漏当空候选，不把整批记为已检查；追加处理继承已消耗额度。

### US-4 暂停继续（P1）

批量响应或部分工具结果保存后暂停，再继续。

验收：已确认响应、工具结果和已发布成员不重复执行；保留原批次成员、授权及额度，不因重组增加预算。

## 3. 功能需求

| ID | 要求 | 验收口径 |
|---|---|---|
| BFR-01 | 合并同主体版本、同记录、同 scope 的已就绪不同谓词任务 | 异主体/版本/记录/scope 或未准入任务不能被带入 |
| BFR-02 | 支持多属性、多关系及混合任务 | 不依赖具体业务 IRI、字段或章节 |
| BFR-03 | 每项回答归属于输入任务，包括空回答 | 检测漏项、重复、错误谓词和越界主体 |
| BFR-04 | 原文可去重，证据及引用权限逐成员校验 | span、事实/辅助角色和注册实体白名单不可串用 |
| BFR-05 | 保留发现、独立核验和服务端接纳分工 | 工具通过不代替原文证明；核验不用发现推理 |
| BFR-06 | 各成员及声明独立判定 | 按真实依赖传播失败，不整批接纳或语义拒绝 |
| BFR-07 | 保留既有身份规则 | 同名不合并；物理身份复用不覆盖成员证明 |
| BFR-08 | 多工具结果一次输入，按所属任务授权 | call_id 配对；依赖新结果的操作仍分轮 |
| BFR-09 | 一次真实请求只计一次成本 | 同时扣参与成员的额度；重组/修复/继续不重置 |
| BFR-10 | 在输入、输出和额度约束内组批 | 发送前缩批；核验拆组不重做发现；不解析截断 JSON |
| BFR-11 | 复用当前状态及暂停继续入口 | 不重做已保存请求；未知结局不当成功或退款；不加快照 |
| BFR-12 | 保留图谱语义及接口使用方式 | 条件/否定/选择组/证据保真；GET 不启动模型 |
| BFR-13 | 完成情况按成员，图谱按当前提交边界保存 | 未发送保持未尝试；已发送漏答保持尝试未完成 |
| BFR-14 | 固定输入并在同等质量下证明提效 | 报告请求、tokens、耗时、P/R/F1、未完成率 |

## 4. 范围边界

不增加多模型并发、工具线程池、通用批处理框架、跨记录汇总、跨文档身份、跨成员语义证明共享、target/facet 级核验分片、云服务、诊断平台、历史回放或数据库表。不修改权威本体。

单成员仍超限时明确未完成，不通过截断原文、减少 facet 或无限重试获得形式完成。

## 5. 成功标准与实施边界

1. US-1/US-2 的合成请求计数、图谱与逐项证据门禁通过。
2. 成员隔离、混合任务、同物理实体、预算及冷继续反例通过。
3. 固定模型/原文/本体/参考/总预算的真实对照完整报告，无静默遗漏或降低覆盖造成的假提速。
4. 默认启用依据真实质量和成本共同判断。用户尚未指定最低提速百分比或质量容差，本规划不虚设已达标数值；工程完成、质量提升和默认启用分别记录。
