# 报告树形交互验收

范围：报告 Word 目录及报告/模板共用图谱树。浏览器合成数据用于前端交互验收，不代表真实模型识别质量。

1. 打开具有多层章节的 Word 报告：目录显示为树；箭头折叠不定位，标题/Enter 定位原文；上下键移动、左右键展开和返回父节点，选中与焦点可辨。
2. 展开包含共享实体和循环的图谱：每个实体只有一个完整分支，其他出现作为引用；引用能展开祖先并定位实体，未关联循环可展开。
3. 点击实体、属性值、关系依据、主体、条件、反证：均保留原文请求，且不意外折叠、选择父节点或形成嵌套按钮。
4. 更新同一运行图谱：新增结果可见，已有展开/选中保留，删除节点不崩溃；切换用户/文档/运行/投影时不继承另一身份的展示状态。
5. 保留长标题换行/完整可读、空目录、空图谱及技术失败提示。折叠隐藏后代；单纯树操作不产生创建/控制请求。

命令与本次结果完成后记录于 `tree-interaction-validation.md`。
