# 报告预览专家意见 v1

2026-09-11：用户要求在报告中心预览提供专家意见入口。该入口承接图谱人工审核，
也允许报告总体意见；不自动修改图谱、提交事实或将剪枝校准标为通过。

## 需求与交互

- Word 文档及静态演示的预览标题旁提供“专家意见”；其他报告详情提供同名入口。
- 抽屉可填写类型（总体、关系错误、属性错误、遗漏、主体挂接、否定条件、误剪枝）、
  原文位置、意见和建议；读取已保存意见及导出 JSON。意见必填，位置/建议可选。
- 当前登录的高级分析师与 QA 可以提交。普通角色只读；意见按作者隔离，
  只展示和导出自己的记录，不借此开放其他用户的识别运行。
- 确认保存绑定服务端核实的报告标识、原件 hash、作者、角色和时间。
  若打开入口时已有识别运行，则可绑定当时的不可变图谱制品。工作器后续更新
  不使此意见漂移到新图谱；原文变化则拒绝保存并保留表单等待刷新。

## API / 持久化

`/api/report-center/expert-opinions`：GET 返回源上下文和分页意见，POST 追加意见。
`/export`：GET 导出当前用户针对该报告的完整意见，保留各意见的原文/图谱版本。
查询使用 document_iri 或 job_id+report_id 二选一，可附 recognition_run_id。
写入使用 request_key 幂等；重复键不同内容 409。作者、时间、源标题由服务端提供。

新表 report_expert_opinions 保存不可变条目（revision=1）、上下文 JSON 和内容 hash，
通过 0036 迁移创建；与哈希链审计在同一事务提交。无编辑/删除接口，需要修订时
追加新意见。来源和识别运行须真实存在、归属匹配且可访问；禁止猜测运行 UUID
跨用户关联，禁止伪造不存在的图谱制品。历史图谱引用必须属于所选运行。

错误：400 请求体校验失败（复用文档分析错误响应）；403 无提交权限；
404 不存在/越权来源；409 源版本或幂等冲突；422 目标组合或来源类型不合法。
响应 private,no-store；只读打开/刷新/导出不启动模型或创建识别任务。

## 实施及验收

1. 规范/契约 → 模型与迁移 → 来源/版本/权限/幂等服务及 API。
2. 预览入口、表单/历史/导出，复用现有 Sheet、表单、API 与查询缓存。
3. 隔离测试覆盖保存重读、身份隔离、伪造上下文、原件变化、重复请求与历史图谱。
4. 前端类型/静态检查及入口交互验证；部署核对实际迁移 revision、健康与来源读取。
人工提交的意见仍需后续汇总和专家校准，不将自由文本自动转换成金标或批准记录。
