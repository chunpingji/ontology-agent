# Section Prompt 与自定义行文恢复

2026-09-15 用户要求恢复 AST 模板定义中的 Section AI 行文：生成 Prompt、编辑 Prompt、试生成自定义报告内容，保存后进入正式的报告预览和 DOCX 草稿。

- Section 增加可选 narrative 配置，保存启用状态、Prompt、所选输入及必需引用；无配置时保持旧序列化/hash。
- Section 作者界面提供 AI 生成 Prompt、手工编辑、输入选择及 AI 行文预览。样例只用于设计写作要求，预览和报告仅使用当前真实图谱/Mock 输入。已有内容项自己的 Prompt 保留；空 Prompt 可继承章节要求。
- 恢复既有 generate-section-prompt 设计接口。预览复用 V2 report-previews，限制为当前 Section 行文，仍使用同一编译、取数、渲染与 DOCX 逻辑。
- 编译时将启用的 Section 行文转换为普通 V2 输出项；作者只维护一份 Section 配置，不保存第二套可独立编辑的内容副本。
- 自定义措辞使用明确的草稿 Prompt 策略，不受旧有限固定措辞菜单限制；输入引用仍需校验。AI 文本仅为未审核草稿，不能视为事实证明、计算结果或签署；正式发布/签署沿用服务端草稿边界。
- AI 生成建议不自动覆盖手工编辑；切换修订、Section、来源或引擎时丢弃迟到响应。GET 不发起模型调用。

验收：Prompt API 角色/失败处理、Section 序列化与编译、输入引用与缺口、子内容覆盖、草稿边界；浏览器验证生成/编辑/保存/预览及迟到结果；真实模型至少生成一个包含图谱输入的自定义段落并核对 DOCX。

使用入口：模板详情 → AST模板定义 → 展开 Section →「Section · AI 行文」。选择本节已关联输入，填写写作要求，点击「AI 生成 Prompt」并采用，或直接编辑「Section 行文 Prompt」；「AI 行文预览」只试生成本节正文。勾选「在报告中生成本节正文」后保存新修订，在「报告预览」生成完整草稿及 DOCX。多个文档来源的模板需在完整报告预览中分别选择来源。

范围：当前 V2 作者界面及 `generate-section-prompt` 已恢复；旧 V1 `preview-section-narrative` 仍指向 V2 迁移提示，不重建旧执行管线。自定义措辞无法仅靠引用检查证明全部语义正确，作者仍须核对；引用校验与草稿标识不等同人工事实审核。
