# Slot 与演示报告兼容契约

状态：2026-09-14 已实施并部署；真实指定模板验收见 [validation.md](validation.md)。

- V2 文档 `source_bindings` 增加可选 `finder_execution_id`；仅当前模板有效引擎为 `finder_legacy` 时由服务端读取同 owner/template/source 的当前已完成且未过期结果。正常快照读取不变，内部作业 ID 不开放。
- V2 模板增加可选 `record_sources`：记录槽位 → 有限本地 Mock 提供方、契约引用及显式筛选参数。默认空且不改变旧模板序列化；业务字段用 parameter 类型契约，不伪造 workflow 审核。仅演示草稿允许 Mock 自动取数。
- `GET /ast-templates/{id}/semantic-sources?source_job_id=...` 读取合法路径/属性/Mock 目录及当前可用状态，不调用模型或开始识别。
- `POST /ast-templates/{id}/suggest-semantics` 接收 V2 草稿及公开源标识，输出按 output_id 定位的语义建议、可选来源目录及未解决项；来源与契约由服务器校验。只改草稿，保存仍走新修订接口。模型只选择目录中的键，不输出任意谓词/来源实现。
- `POST /ast-templates/{id}/configure-slot` 接收草稿、公开源标识和内容项选择，返回同一格式的绑定补丁，不保存修订；维护者可配置，其他角色不能调用写入建议端点。
- 模板编辑的手工来源选择与 AI 建议均生成同样的 Binding/Input/Render。通用旧 Slot 迁移在 origin.legacy_slot 保留 coverage_refs 选中的完整覆盖、Slot/章节 Prompt 继承及必填/缺失意图；有歧义的短名、主体/时间限制和未匹配外部提供方仍明确待确认。指定 v2.4 修订没有旧 Slot 定义，按样例结构重新关联实际字段。
- AI 每次最多分析 4 个未配置项，明确选择输出形式和目录字段；多对象不能直接当单对象段落。同物理表的未编辑表头合成一个表格内容项，表尾备注独立保留；序号由现有表格渲染生成。返回前执行编译校验。
- Finder/Mock 报告来源包携带演示标识，预览、历史与 DOCX 可见；服务端拒绝正式用途和签署。执行完成表示读取与渲染完成；材料是否齐备由独立状态及覆盖缺口表达，不表示事实核验完成。
- 空内容项在覆盖中报告配置缺口；模型或来源失败保留缺口，不降格为成功。两种引擎切换不得自动改变已保存的语义定义。

- Mock 筛选支持固定值和已有输入的字段路径；排产必须限定设备、产品及起止日期（日期范围不超过 62 天）。当前有限数据读取超过预算会明确拒绝，不返回截断集合。
- Finder Profile 版本升为 2，新增报告所需的稳定原文列键。旧展示缓存按既有版本检查标为过期，需显式重新识别；切换引擎、GET 或刷新目录都不会启动识别。
- `source_text` / `source_field` 是 Finder 演示投影，普通事实来源没有对应语义时返回“不支持/不可用”，保留模板原定义。正常数据属性投影继续使用完整 IRI 和声明类型。

- 编译器版本 `output-compiler-v2.4`：外部记录集合按单行推断字段类型，避免编号误变为嵌套列表而无法按键连接。Mock 设备规格/材质/位置来自完整属性 IRI；多个值不任取第一项。
- 本地引用式行文使用有限节点目录和必需索引，响应转换为原有 ContentNode 后继续全部授权引用/措辞校验；不使用任意文本代替输入引用。请求总预算和输出节点上限仍由服务端执行。
- 历史列表 DTO 显式返回 `demonstration`，避免依赖只在详情存在的 narratives；不向列表扩大发送整份行文结果。
- 旧 Slot 的全部必填 coverage/属性必须被选择；含主体、时间、逆向路径、复杂集合或缺失策略的定义保持待详细确认，不能以有限菜单选择静默丢失原约束。
