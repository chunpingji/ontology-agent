## 1. 需求与澄清

- 引擎对输入本体和文档工作，最终交付带原文证据的关系图谱；不内置行业类型、编号格式、章节偏好或领域闭环。
- 强模型使用项目配置的 Qwen；GLiNER2.5、SKOS、结构/摘要检索、可选外部实例来源和确定性校准作为通用工具能力。
- 标准工具按冻结策略和阶段裁选；本次新增指称候选查询，单位校准与适用 SHACL 仍由程序按同一契约保证执行，注册能力与模型主动调用分别验收。
- 用户已确认本项目 Qwen 服务支持 OpenAI Responses API，027 新运行以该协议接入；工具参数、阶段回答、最终图谱是不同契约。旧 Chat Completions 调用方保留原协议，新路径不自动回退。
- 按用户确认的 OpenAI Harness Engineering 方向设计：研发时提供可导航规范、机械边界和验证反馈；运行时让模型按需使用授权上下文和工具，由程序保证预算、阶段核验及最终图谱接纳。
- 用户已要求按 Spec Kit 实施运行代码及验证；不自动部署、发布或清理既有运行数据。
- 021/022 提供现有文档分析与执行基础；026 是特定报告实验。027 不改写其历史结果，通用性和原生工具对接按本规范实现。

- 2026-09-17 界面澄清：分析历史采用卡片；点击后从右侧抽屉查看详情，桌面宽度为页面的 4/5，窄屏全宽。关系图谱采用类似本体工作台的节点连线交互，点击节点显示其属性和关系，保留原文证据定位。文档分析结果聚焦关系图谱，不展示覆盖与未完成范围及其计数；运行状态和控制保留。关闭详情只关闭视图。

## 2. 功能要求

| ID | 要求 | 验收 |
|---|---|---|
| FR-01 | 文档根类型、合法类/谓词和约束来自输入本体，不按具体 IRI、业务字段或章节名称选算法 | 应用本体一致重命名并同步参考后处理语义不变；标准词表 IRI 保留 |
| FR-02 | 原文是文档声明证据；结构、摘要、NER 和外部元数据只提供各自允许的线索 | 摘要或外部命中不能单独支持关系；引用精确回放 |
| FR-03 | 支持同类多实例、无编号提及和记录组成主体；物理提及复用，跨提及指代/共指绑定有独立原文证明 | 名称变体/正文与表格同指的正例，同名异对象、粗品/成品、歧义代词的反例；不按名称直接合并 |
| FR-04 | 通用工具有明确参数/结果契约，以 Responses API 标准函数调用接入 Qwen | 平铺 tools、output 中 function_call、匹配 call_id 的 function_call_output 及使用结果的后续回答；阶段 JSON 使用 text.format |
| FR-05 | 权限、声明版本、语义前置条件和额度由服务端决定 | 伪造状态、任意来源/路径、过期引用不能执行；模型无法写图 |
| FR-06 | 生成与独立核验阶段隔离，核验仅评价冻结目标 | 核验输入包含声明完整内容及所需授权依赖；缺失、重复、错 hash 或修改目标均不能通过 |
| FR-07 | 引用错指仅在授权范围唯一修复；缺证按维度补检索 | 新引用/证据重新核验；无命中不等于否定 |
| FR-08 | 所有模型续轮和修复共享实际请求预算，并限制每次显式启动/继续的连续运行 | 每 lineage 默认最多 4 次；连续运行达到冻结的时间/请求限额时保存已付费结果并暂停；继续不清空累计账本 |
| FR-09 | 数量保留原值、区间/比较符、端点语义和单位归属；精确换算 | 标量不截区间、未知单位不猜测、同量纲不同指标不混淆 |
| FR-10 | SHACL 校验声明表示并报告执行/focus 覆盖 | 空图/未执行不记通过；不改写真实业务超限值 |
| FR-11 | 外部来源可选，查询与身份确认分开；文档/外部字段分来源 | 无来源仍可抽取；未知对象保留；同名不产生全局等同关系 |
| FR-12 | 图谱保留属性、单对象关系、选择组、条件/模态/否定及证据 | 备选组不拆普通边；已核验孤立节点不丢失 |
| FR-13 | 组成员后续抽取保留关系适用范围；失效依赖阻止继续 | 同一成员在不同组内的任务、覆盖与属性不串用 |
| FR-14 | 暂停继续复用当前权威工作、精确请求结果与展示缓存 | 初始输入加当前精确引用派生续传内容，不重复存储累积会话；唯一当前授权可恢复角色与权限；保存响应后不重复调用，未知结局不当完成或退款 |
| FR-15 | 最终图谱与完成度一起交付，未决/拒绝不作成立事实 | 空图不代表全文无事实；投影丢失计漏检 |
| FR-16 | 工程、协议、质量和成本分别验收，金标不进入识别 | 保留集跨文档/本体，固定预算报告实体/属性/关系 P/R/F1 |
| FR-17 | 模型能按任务定位上下文、选择工具，并从具体错误获得反馈 | 原文/摘要/候选角色可区分；按需工具序列共享预算；未知函数/坏参数反馈可保存并继续，错误指出字段或缺失维度，不静默代改 |
| FR-18 | 开发规范、实现边界和结果检查可被编码代理发现与执行 | 每项任务可定位契约、代码及检查；越界依赖/契约漂移被测试发现；观察到的失败进入相应回归，不能把计划标为完成 |
| FR-19 | 分析历史卡片打开详情抽屉；图谱以节点和有向关系展示，节点详情列出属性、关联单边/关系组及证据 | 桌面抽屉占页面 4/5，窄屏全宽；根与孤立节点可选；组、方向及断言限定保真；默认显示实体名、本体关系名、属性名和值，证据以用途与序号命名；文档分析结果不展示覆盖与未完成范围及其计数，保留运行状态和控制；内部 ID、IRI 和版本放入默认折叠的技术详情，缺名明确提示，业务编号原值保留；关闭/刷新/切换仅查询结果，不启动或取消任务 |

| FR-20 | 按确认的 Drawer 设计展示真实流式输出及 Harness 运行信息 | Thinking/操作/上下文收纳在 Harness运行信息内并默认折叠；提示词与窄化 Schema 卡片双 Tab 绑定同次实际调用；只读切换保留滚动，连接与运行状态分开；输出仍须完整校验后入图 |

## 3. 范围边界

不新增文件解析器、连接器平台、Agent 框架、图数据库、云端模型、自动训练、历史回放、运维诊断平台、业务提交或权威本体修改。旧冻结实验和运行不原地升级。

关键场景：新本体同算法抽取；Qwen 原生工具往返；恰选一个的组和成员属性；带单位区间与端点；关闭外部来源/未知标识；工具结果保存后暂停继续。原生协议不支持或预算不足均明确保留未完成状态。

## 5. Drawer 实时观察增量（FR-20，2026-09-17）

已由用户澄清：按 design.pen「应用分析-文档分析」实施，桌面 Drawer 4/5；图谱为主结果。Harness运行信息默认折叠，集中模型/工具启用配置、实际调用、预算用量和版本。LLM 正文真实增量显示；Thinking、操作、上下文收纳在 Harness运行信息内，各自默认折叠；外部仅保留实时正文。Thinking 仅呈现服务端明确返回的可读 reasoning，不展示 encrypted_content。操作包含模型请求、工具、确定性校验和已提交图谱更新，不能将观察内容当作已接受事实。

上下文展开后默认提示词 Tab，另一个为本体 Schema 卡片；同一次实际请求的 instructions、input、回答格式与窄化卡片绑定同一 call_id，展示原文/摘要角色及未解析约束，不能补造本体约束。原始输入只屏蔽不透明 reasoning 字段并标注，不修改实际提交内容。切换 Tab 保留滚动位置，GET/订阅不启动模型。上滚停止输出自动跟随，提供回到最新；暂停/结束停止流式光标，连接状态单列。历史运行无观察数据明确提示。

最小范围：复用现有 Responses 调度、运行 SSE、当前展示分区和鉴权。只保留当前请求上下文、当前输出以及最近 30 项操作，文本窗口最多 128 Ki 字符并明确截断；不保存 token 历史或新增恢复入口。缓存不参与工作状态、模型输入、证明与运行水位。上下文被下一次请求替换后旧 call_id 返回冲突，不返回错配内容。

## 6. 关系工具校验分工（2026-09-17，用户已确认实施）

模型提出候选及原文语义意见；每条冻结关系必须在核验阶段由模型调用 validate_graph，读取服务端本体菜单、引用和实体身份检查结果后再回答。工具结论只表示适用约束与身份检查，不证明原文事实。未调用、失败、未完成或与当前声明/上下文/本体不匹配的结果不得接纳。同类型且完全相同原文提及已登记时，不得因新任务再次创建实体；同名不同位置不据此合并。

复用现有工具调用账本、当前协议与预算；属性值校准/SHACL 仍由控制器在原有前置条件下执行。此增量更新前文 controller-only 的 validate_graph 范围：仅属性分支保持 controller-only。

## 7. 指称消解、关系证明和连续预算（用户已授权实施）

本次只处理当前运行内的指称。新提及可绑定同轮声明中的新实体来源与已登记、已有类型证明的目标；同名或空白差异只是候选检索线索，不能授权任意合并两个既存图节点、修改旧运行或作跨文档身份合并。确切物理位置和已核验类型一致时复用实体；跨位置复用须独立证明同一对象及作用域，类型、批次、工艺阶段、个体/群体粒度冲突或代词多解时保留未决。

新增候选查询只返回授权的目标实体、提及、原文及区分信息，不调用模型或产生同指结论。候选原文仅供绑定核验，不扩大本轮事实发现范围。实体、指称绑定、完整谓词断言分别冻结和核验；新绑定可以在同一 verification 请求中作为独立目标评价，但不能预先冒充已通过的桥接。

关系声明必须提供主体来源、逐对象来源、谓词断言和所依赖的指称绑定。只证明对象出现、类型合法、并列共现或图可达，不能证明指定主谓宾。未证明的关系不进入后继展开；真正父子组成关系与合法表头/跨句归属仍保留支持路径。本体及具体产品/谓词不为本次案例改写。

新增别名/提及保留各处原文及独立判定，相关声明保留条件、极性和组范围；规范实体复用避免生成重复主体任务。继续使用一份当前工作状态、一份最新展示和独立调用账本，不引入历史执行快照。

连续预算只随显式启动/继续开启新窗口，默认 30 分钟或 32 次识别请求，先到者暂停。已预留的失败请求照常计费；在新请求预留前检查限额，已付费响应与工具结果先保存。自动租约恢复不重置窗口，显式继续仅重置窗口基线，不改变 lineage/总任务额度和累计请求。达到限额表示尚未完成，可通过已有继续入口处理剩余内容；旧运行缺少相应冻结策略时沿用原行为。

验收分开记录：名称变体同指、同名异对象、歧义代词、并列/父子关系正反例及冷继续工程检查；固定原文/本体/模型/参考与预算的真实质量和成本比较；在线部署状态。工程通过不能替代后两项。
