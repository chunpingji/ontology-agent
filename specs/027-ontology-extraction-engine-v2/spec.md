# 027 通用本体约束文档抽取引擎

日期：2026-09-16。状态：需求与模块设计细化，尚未实施。本文承接[总体方案](../../docs/文档抽取引擎2.0设计方案.md)，不代表已创建特性分支、切换入口或完成真实模型验收。

## 1. 需求与澄清

- 引擎对输入本体和文档工作，最终交付带原文证据的关系图谱；不内置行业类型、编号格式、章节偏好或领域闭环。
- 强模型使用项目配置的 Qwen；GLiNER2.5、SKOS、结构/摘要检索、可选外部实例来源和确定性校准作为通用工具能力。
- 十项标准工具中，单位校准与 SHACL 由程序按同一契约保证执行；模型可见工具按阶段裁选，注册能力与模型主动调用分别验收。
- 用户已确认本项目 Qwen 服务支持 OpenAI Responses API，027 新运行以该协议接入；工具参数、阶段回答、最终图谱是不同契约。旧 Chat Completions 调用方保留原协议，新路径不自动回退。
- 按用户确认的 OpenAI Harness Engineering 方向设计：研发时提供可导航规范、机械边界和验证反馈；运行时让模型按需使用授权上下文和工具，由程序保证预算、阶段核验及最终图谱接纳。
- 本轮交付可直接编码的模块计划、数据契约、任务与验收步骤，不实施运行代码、部署、模型调用或数据清理。
- 021/022 提供现有文档分析与执行基础；026 是特定报告实验。027 不改写其历史结果，通用性和原生工具对接按本规范实现。

## 2. 功能要求

| ID | 要求 | 验收 |
|---|---|---|
| FR-01 | 文档根类型、合法类/谓词和约束来自输入本体，不按具体 IRI、业务字段或章节名称选算法 | 应用本体一致重命名并同步参考后处理语义不变；标准词表 IRI 保留 |
| FR-02 | 原文是文档声明证据；结构、摘要、NER 和外部元数据只提供各自允许的线索 | 摘要或外部命中不能单独支持关系；引用精确回放 |
| FR-03 | 支持同类多实例、无编号提及和记录组成主体；身份合并有独立证据 | 同名异对象、无名称记录、复合标识均有正反例 |
| FR-04 | 通用工具有明确参数/结果契约，以 Responses API 标准函数调用接入 Qwen | 平铺 tools、output 中 function_call、匹配 call_id 的 function_call_output 及使用结果的后续回答；阶段 JSON 使用 text.format |
| FR-05 | 权限、声明版本、语义前置条件和额度由服务端决定 | 伪造状态、任意来源/路径、过期引用不能执行；模型无法写图 |
| FR-06 | 生成与独立核验阶段隔离，核验仅评价冻结目标 | 核验输入包含声明完整内容及所需授权依赖；缺失、重复、错 hash 或修改目标均不能通过 |
| FR-07 | 引用错指仅在授权范围唯一修复；缺证按维度补检索 | 新引用/证据重新核验；无命中不等于否定 |
| FR-08 | 所有模型续轮和修复共享实际请求预算 | 每 lineage 默认最多 4 次；不足时未完成，不跳过核验 |
| FR-09 | 数量保留原值、区间/比较符、端点语义和单位归属；精确换算 | 标量不截区间、未知单位不猜测、同量纲不同指标不混淆 |
| FR-10 | SHACL 校验声明表示并报告执行/focus 覆盖 | 空图/未执行不记通过；不改写真实业务超限值 |
| FR-11 | 外部来源可选，查询与身份确认分开；文档/外部字段分来源 | 无来源仍可抽取；未知对象保留；同名不产生全局等同关系 |
| FR-12 | 图谱保留属性、单对象关系、选择组、条件/模态/否定及证据 | 备选组不拆普通边；已核验孤立节点不丢失 |
| FR-13 | 组成员后续抽取保留关系适用范围；失效依赖阻止继续 | 同一成员在不同组内的任务、覆盖与属性不串用 |
| FR-14 | 暂停继续复用当前权威工作、精确请求结果与展示缓存 | 保存响应后不重复调用；新增证据的权限与角色可恢复；未知结局不当完成或退款 |
| FR-15 | 最终图谱与完成度一起交付，未决/拒绝不作成立事实 | 空图不代表全文无事实；投影丢失计漏检 |
| FR-16 | 工程、协议、质量和成本分别验收，金标不进入识别 | 保留集跨文档/本体，固定预算报告实体/属性/关系 P/R/F1 |
| FR-17 | 模型能按任务定位上下文、选择工具，并从具体错误获得反馈 | 原文/摘要/候选角色可区分；按需工具序列共享预算；未知函数/坏参数反馈可保存并继续，错误指出字段或缺失维度，不静默代改 |
| FR-18 | 开发规范、实现边界和结果检查可被编码代理发现与执行 | 每项任务可定位契约、代码及检查；越界依赖/契约漂移被测试发现；观察到的失败进入相应回归，不能把计划标为完成 |

## 3. 范围边界

不新增文件解析器、连接器平台、Agent 框架、图数据库、云端模型、自动训练、历史回放、运维诊断平台、业务提交或权威本体修改。旧冻结实验和运行不原地升级。

关键场景：新本体同算法抽取；Qwen 原生工具往返；恰选一个的组和成员属性；带单位区间与端点；关闭外部来源/未知标识；工具结果保存后暂停继续。原生协议不支持或预算不足均明确保留未完成状态。
