## 来源结构与本体边界

数据集适配层允许显式引用五个现有 Mock ORM 模型及字段，这是源格式适配。
该层不包含本体 IRI、车间编号、类型后缀或字符串拆分。
通用层只消费映射和当前本体。数组中的源标签由字段配置指定，不能从中文名猜谓词。

继承/定义域校验复用当前本体引擎提供的数据，并核验并/交集语义；
不直接导入独立 Harness 的候选或模型协议。如确需共享纯本体辅助函数，限定在现有本体服务边界内。

来源键组用于查询，本体键组用于语义核对；同源同号的重复记录不会被查询代码去重合并。
Mock 表现有 code 唯一约束的调整不属于本期；异域同号反例可由隔离来源 fixture 表达。

## 初始配置与生效

前端在已支持来源中提供“应用初始映射”操作，使用现有映射写接口和权限。
配置文件只提供生产区域/设备的声明；不自动覆盖用户已存在配置，不播种或修改任何 Mock 实例。
相同来源绑定已经存在时展示差异或使用它，不另建重复绑定。
保存有效配置后查询默认可用，不新增功能开关或同步任务。

部门、角色、小组成员目录与源读取能力可复用同一服务；
缺少合法领域属性或存在对象层级疑问时显示未完成配置，不能由代码造本体补齐。

## 一致性与失败处理

- 每个批次使用一次读取到的来源行及映射配置，不产生永久数据副本。
- `mapping_revision` 纳入子绑定版本；下次请求读取最新配置。
- 编辑映射沿用现有 CAS；查询读失败按契约返回不完整，读取不会更新任务状态或 health。
- 只读候选不会绕过旧未验证候选禁止发布的门禁。
- 元数据新增字段不写作 T-Box 公理；回写链路不得把来源键误导出为 `owl:hasKey`。
- 不新增长效缓存；无需来源同步或缓存失效任务。
- 来源卡片浏览复用批查询：仅指定一个映射时允许无筛选条件，分页返回总数及下一页偏移；
  总数未知与分页分别表达。复用 Sheet，关闭时取消请求，浏览及翻页不生成运行或事实。
