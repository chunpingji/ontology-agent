# 032 属性观察、确定性解析与收尾校准

日期：2026-09-19。状态：实现、工程验证及本机部署核验完成；未完成真实文档模型评测。

最终行为见 [实现记录](implementation.md)，实际检查及结果见 [验证记录](quickstart.md) 和 [部署记录](deployment.md)。

## 需求与澄清

用户明确要求实施：参数值和数据类型由确定性引擎解析；首次校验未完成时先保留候选，在实例和关系补全后结合原文校准。

1. LLM 提出来源、主体及 Schema 属性候选；数值、日期、单位、区间及精度由确定性解析产生。数据类型解析与业务属性含义分别表达，解析成功不授予事实资格。
2. 精确原文有效但主体/含义/单位尚不清楚的观察可展示为待校准候选。当前映射被否定或与数据类型冲突时保留原字段及失败原因；越权、不存在或篡改的引用拒绝。
3. 唯一确定的字段标签边界可自动收窄；不能跨字段、跨行或靠最高分修正引用。保留实际模型请求/回答，事实仍经独立语义及确定性检查。
4. 常规识别到达本轮边界后，只对获得相关新实体、关系或原文证据的未决项执行有界校准；复用原任务与调用预算。暂停继续不重跑已完成校准；无新证据不重扫。
5. 待校准候选独立展示，不参与事实推理、数值计算、报告或关系端点。SHACL 因前置失败未执行时明确携带具体根因。
6. 新建运行默认启用；不修改真实运行、不新增表或另一套事实存储，不为旧执行策略增加兼容分支。实施阶段不部署；后续按用户“请部署”的明确授权更新本机服务。

## 验收

- `时间：2026年02月` 可确定性拆分标签和值，解析为年月 `2026-02`；不能因此认定为计划生产日期。
- `00123` 字符串保留前导零；年月不补日；区间不伪装标量，来源单位不足时保留原值。
- 有效原文中的未决字段在图中无正式属性时仍可查看原文和失败原因；无效引用不混入。
- 后到相关实体/关系仅触发受影响项；无关图变化不触发；已解析和已支付结果冷继续可复用。
- 校准通过后进入事实属性并消除对应待办；仍未决的保留，不循环追加预算。
- 现有证明、原文授权、跨用户隔离、字段消歧及恢复回归保持。
