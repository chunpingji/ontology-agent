# 030 文档阅读上下文与属性消歧

当前调度补充：[031](../031-semantic-record-discovery/spec.md) 以语义候选替换普通类卡穷举；保留本规范的阅读组、字段去重与证据权限，字段在相关普通发现之后释放。旧穷举/字段优先游标不保留兼容执行分支；以下部署记录仍描述 030 当时结果。

日期：2026-09-19。状态：实现、工程验收及部署核验完成；真实模型质量验收另行进行。承接 029；用户已授权一并实施目录跳过、短章节联合阅读、CMCReport 编号/密级及属性消歧。结果见 [quickstart.md](quickstart.md)，部署见 [deployment.md](deployment.md)。

## 目标

1. 已确认的 Word 目录不消耗事实识别和摘要模型调用，原文与预览完整保留。
2. 短章节在明确语义连续时联合阅读，标题/祖先标签与值共同提供上下文；不改变原文结构、主体和条件边界。
3. CMCReport 可识别原文明示的文档编号和密级；不默认必填、唯一或枚举。
4. 对低信息量编号等字段先保存来源及值，再判断主体/属性归属。同一物理字段不因类卡不同重复分析；无相关新证据不重试，未决不冒充事实。
5. 字段去重仍在类卡扩散前完成，但新运行按阅读顺序先执行可用的普通实体发现，再执行对应字段消歧，避免运行开头连续出现无主体字段任务。

## 澄清与范围

- 目录按已确认条目识别，不能按整节标题删除。目录后的无标题正文和正文误用 TOC 样式必须保留。
- 联合阅读仅限有明确字段结构或续文依据且符合边界的连续内容；字数只限容量。相邻不同物料、批次、样品或否定/条件不自动归为同一实体。
- 编号/密级本期只适用于 CMCReport；保留字符串原貌，不作为自动身份合并键。权限控制和密级排序不在范围。
- 属性消歧比较合法的主体/属性候选对；缺值、本体缺属性、主体未找到、多候选歧义及技术失败分别表达。候选唯一不等于证据充分。
- 纯字段组没有普通实体来源时，最多延后到下一个普通阅读组之后；整份文档都只有字段时直接执行。调度延后不扩大字段的原文或主体权限。
- 一个字段首轮消歧，相关主体/证据改变后至多一次自动再试；核验与工具调用仍受原总调用预算限制。不因重开任务返还已用额度。
- 普通明确事实继续使用既有独立核验。混合记录中的其他内容不能因一个字段待消歧而丢失。
- 新运行默认开启；旧制品不重写，当前按 031 使用新建运行验证。本次不自动重启服务或发布混有其他草稿的线上本体批次。

## 验收

- A01 有/无目录标题、TOC 域和目录样式的确认条目保留预览及定位，不成为识别目标或摘要材料；邻接正文保留。
- A02 历史 IR 与运行可按原哈希加载；新目录角色参与来源身份。
- A03 标题和值分开、同父连续字段和明确续文可联合阅读；原始锚点和各记录边界保留；歧义边界不自动合并。
- A04 联合阅读实际减少重复发现任务，不仅减少展示章节数；覆盖仍明确记账。
- A05 本体仅新增批准的两属性，旧三元组保留，其他法规文档不继承；隔离元数据/World 和模型卡一致。
- A06 同字段跨多类卡只生成一个消歧工作项；只有标签无值不创建虚构值。
- A07 比较多个合法主体与属性；同值不同设备/批次不混挂，不凭相邻/格式/最高分确定归属。
- A08 相关候选变化可唤醒一次；无关实体、顺序变化不唤醒；暂停继续不重复付费或发布。
- A09 消歧属性经过正常独立核验后入图；未决、缺值、本体缺口在 Harness 可见，不计作已确认事实。
- A10 路由、调用、未决与覆盖分别验收；不凭工程用例宣称真实模型质量提升。
- A11 有普通来源时首个字段模型请求之前已有可用的普通实体发现；新策略暂停继续复用当前候选与已付费结果，不重复准入或重新计费。
