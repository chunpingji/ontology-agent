# 计划与内部契约

宪章核查：不改 TTL、数据库结构、业务事实接纳和公共 HTTP 契约。
复用当前状态、本地模型客户端和现有投影，不新增依赖或历史恢复入口。
范围已由用户澄清，按下列顺序整合实施。

1. 在工具传输处投影 MentionData，存储及确定性消费保持完整对象；统一投影计量和返回。
   在线和评测默认单工具结果上限设为 8192。
2. 在 Responses 边界编码引用并还原响应；映射从当前规范输入派生，
   不新增持久状态。完整结果继续进入现有账本，恢复时重新构造模型视图。
3. 纯函数裁剪 Schema；核对本地端点能力后去掉提示词副本。
4. 扩展 compact_model_context，按核验目标缩小卡片、共享完全相同定义；
   仅在已完整注入原文时移除 inspect_evidence 的模型暴露。
5. 定向协议、权限、预算、恢复回归及固定请求分词比较；当前实现新建运行验收。
   部署前核实真实活动任务；不把旧运行兼容作为验收条件。

内部边界：投影不修改规范证据、冻结卡片和身份，也不赋予成员额外权限。
容量预检、请求哈希和实际发送对应同一模型视图；原文字符串逐字保留。
