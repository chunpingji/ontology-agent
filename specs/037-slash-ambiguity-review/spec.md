# 斜杠关系歧义人工确认

## 需求

独立文档分析已经定位两个对象及其关系，但原文斜杠不能证明它们是备选、共同参与或并行时，系统应在该原文位置生成待人工处理的任务。任务展示原文定位和两道选择题：此处的含义，以及该解释的作用范围。未经回答的歧义继续保持未决。

图谱分析页面标题栏右上角以任务图标及待处理数量显示当前运行的入口。点击图标在右侧 Drawer 中查看、回答任务；没有任务时可查看空状态。图谱主体不铺开任务表单。

含义选项为“备选，择一”“均参与且并行”“均参与，先后或时间未说明”“仍无法判断”。范围选项为“仅此处”“整篇文档”“整个平台”。回答“仍无法判断”只允许“仅此处”，不建立可复用解释。

整篇文档及整个平台只复用到同样由斜杠造成的、关系谓词与两侧对象本体类型相同的未决任务；不把任何含斜杠的编号、日期或其他领域关系自动解释为备选或并行。整篇文档限该用户上传的相同文档；整个平台可跨用户使用，但只有高级分析师可以创建平台级解释。较窄范围的确认优先。

人工回答作为独立解释展示，保留模型的原始未决状态及原文证据，不自动把关系转换为已证明事实。查看页面不触发模型运行。仅运行所有者可以查看和回答其任务。

## 验收

1. 两设备关系因斜杠未决时，图谱中出现带原文定位的两道选择题；普通未决和编号中的斜杠不误触发。
2. 提交后任务显示确认含义及作用范围，原关系仍显示模型未决。
3. “仅此处”不影响另一处；“整篇文档”只覆盖同一用户同一文档中的同类歧义；“整个平台”覆盖其他用户的新同类任务，但不能由非高级分析师提交。
4. 非法选项、过时任务和跨用户提交被拒绝；较窄范围的回答优先。
