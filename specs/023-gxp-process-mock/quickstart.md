# 验证场景

在已准备依赖的 `frontend/` 启动开发服务，登录后访问 `/mock/gxp-process`。

1. 确认底部导航顺序为抽取配置、报告模板、GxP工艺规程配置，且仅当前项选中。
2. 确认 25 个步骤、默认保温反应和四个配置区；搜索氮气并切换操作，再返回保温反应。
3. 修改温度范围、新增参数或步骤、复制操作，确认不同操作的编辑互不覆盖。
4. 通过权限设置切到只读演示，确认编辑/保存受限；恢复可编辑。
5. 校验、预览、填写变更说明、保存及模拟提交；确认会话提示，刷新恢复示例。
6. 在 1440px 与 1024px 宽度检查布局、滚动和弹窗，确认无控制台错误或业务 API 请求。

浏览器验证采用合成登录状态，仅验证静态前端，不代表真实后端、权限服务或审核集成已验收。
