# 验证场景

在已准备依赖的 `frontend/` 启动开发服务，登录后访问 `/mock/gxp-process`。

1. 确认底部导航顺序为抽取配置、报告模板、GxP工艺规程配置，且仅当前项选中。
2. 确认 25 个步骤、默认保温反应的四个 Tab，初始展示“过程参数与记录配置”；搜索氮气并切换操作，再返回保温反应。
3. 修改温度范围、新增参数或步骤、复制操作，确认不同操作的编辑互不覆盖。
4. 通过权限设置切到只读演示，确认编辑/保存受限；恢复可编辑。
5. 校验、预览、填写变更说明、保存及模拟提交；确认会话提示，刷新恢复示例。
6. 在 1440px 与 1024px 宽度检查布局、滚动和弹窗，确认无控制台错误或业务 API 请求。

浏览器验证采用合成登录状态，仅验证静态前端，不代表真实后端、权限服务或审核集成已验收。

入口：步骤树“反应与保温反应 → 过程取样”。[设计与 ICH 原文映射](sampling-design.md)列明原则、字段和适用边界。

2. 切换固定间隔后显示小时数，事件模式不要求隐藏间隔；混合样需论证，即时处理需方法和时间，终点用途需至少一个必需终点项目。
3. 可增删取样点、检验项目；支持定性和数值准则。复制方案或切换操作互不覆盖；保温反应的料温记录仍默认每 3 小时。

5. 切换 Tab 保留各区编辑，支持方向键与 Home/End；只读/停用下可切换查看但禁止修改。窄屏标签栏可横向滚动。记录预览展示所有配置及空白记录，不预填符合结论。刷新恢复示例。

## 生成批号工艺演示验收（2026-09-10）

1. 在 `/mock/gxp-process` 的“版本历史”右侧点击“生成批号工艺”。下拉框提供两份研发 CMC 静态示例：A 合成反应路线（10 个操作）、B 结晶纯化路线（8 个操作）。
2. 填写批号，预览示例条款及参数，勾选保留的操作；切换报告恢复该报告的适用操作选择。空白/非法/会话内重复批号、零操作选择均禁止生成。
3. 生成后按报告顺序展示批操作，查看来源章节、编辑参数、保存当前操作版本。切回通用模板或其他批草稿，确认各自选择、参数、版本记录和未保存状态保留。
4. 导出 JSON，核对批号、报告示例快照、生成时的保留/裁剪清单、当前编辑及会话版本。复制操作时保留正确来源；新增步骤不与裁剪后已有编号冲突。
5. 切换只读后禁止生成与修改，但允许切换查看及导出；刷新恢复通用模板并清除会话内批草稿。

实现范围：使用内置通用操作结构与固定 CMC 示例映射。不是实际报告解析，不连接报告中心，不建立真实批次、审核或持久化记录；数值和条款均为演示，取样批准依据及未给出的检验限度留空。
