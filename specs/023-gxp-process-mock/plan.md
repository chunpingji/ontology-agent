1. 已从 Pencil 核对文案、结构及样例，用户已澄清为静态 Mock。
2. 复用 dashboard layout、导航模型和 UI 组件；新增 `/mock/gxp-process` 页面及独立 Mock 数据/组件。客户端状态保存各操作的编辑和会话草稿，刷新恢复示例。

## 过程取样实现

1. 已澄清为现有 Mock 内 OP11.03 的配置扩展；直接核对 ICH 官方 Q7、Q9(R1) PDF，字段映射及边界记于 `sampling-design.md`。
2. 独立的取样数据模型、条件校验和配置组件接入 Operation；复用原事件/检查/审核组件及不可变会话状态。取样方案随复制和快照一起保存。
3. 用专用方案、取样点、样品流转、检验表替换取样操作的空参数区，并接入记录预览。格式校验与正式批准分开，保留草稿编辑能力。
4. 运行定向逻辑测试、ESLint、TypeScript 和静态浏览器验收，检查默认留空、条件校验、状态隔离、只读、响应式及无业务请求。

布局调整：按用户要求将过程取样的七个配置区置于现有 Tabs 组件，保留父层操作状态、公共保存栏与完整预览；共享事件/检查/审核区复用同一份组件。验证只读时标签可用、非当前内容隐藏、键盘导航、跨 Tab 编辑与窄屏滚动。

保温反应布局调整：为该操作标记 Tab 展示，并让复制操作继承；四个原配置区复用现有内容。其他普通操作继续沿用既有展示方式。验证默认参数页、参数引用同步、隐藏页错误校验、只读切换和复制隔离。
