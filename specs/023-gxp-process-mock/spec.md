# GxP 工艺规程配置静态 Mock

## 范围与澄清

依据用户确认的 Pencil `design.pen` / `Mock-GxP-工艺`，实现可交互的静态页面。沿用当前导航，在“抽取配置”“报告模板”之后提供“GxP工艺规程配置”。用户本次明确要求静态 Mock，保存、权限切换及提交仅为会话内演示，不产生真实配置、审核或业务事实。

## 验收要求

- 展示画板的 25 类工艺步骤，默认选中 OP11.02 保温反应；可搜索、展开及切换操作。
- 展示基础属性、过程参数、时间事件、操作检查、审核处置预案、变更说明及操作栏；沿用画板示例和现有视觉样式。
- 提供新增步骤/操作、复制、启停、表格编辑、预览、校验及保存反馈。切换操作时保留各自的会话编辑，不把保温反应的规程自动套给其他操作。
- 明示 Mock、示例预设和会话保存范围，不把示例当作法规限值或真实执行结果。
- 只读演示下禁止修改；未登录沿用登录守卫。页面交互不请求业务接口或启动模型任务。
- 桌面步骤树与配置区并列，较窄屏幕可访问完整内容，表格在自身容器内横向滚动。
- 保温反应及其复制操作的四个配置区使用 Tab：01 过程参数与记录配置、02 时间与事件配置、03 操作检查项目、04 审核与处置预案。默认第一项，跨 Tab 编辑保留；只读/停用时可切换查看。基础属性、变更说明及操作栏公共展示，料温默认每 3 小时记录保持不变。

## 过程取样配置扩展（2026-09-10）

用户要求按 ICH 设计现有“反应与保温反应 → 过程取样”（OP11.03）配置页面，沿用静态 Mock 范围。不更名其他步骤，也不改变保温反应的温度记录默认值。

- 按 ICH Q7 §8.30–8.35、§6.52、§6.60、§11.11–11.15 及 Q9(R1) §3–4 组织取样方案、触发规则、点位/相别/数量、代表性依据、防污染、即时处理、保存运输、检验方法/接受准则、事件检查和审核处置。
- 取样间隔、数量、样品处理时限及检验限度由批准规程确定，初始留空并提示待配置；保温温度记录频率不自动成为取样频率。可添加/删除取样点和检验项目。
- 区分过程监测/调整与终点判定。Q7 §8.36 的监测/调整例外不能覆盖所有检验；超标、分析无效、样品完整性异常分别配置处置，复测/重取样关联原始记录和批准程序。
- 配置校验检查完整性、正数/整数、区间、条件字段及终点所需项目；不宣称完成科学适用性或 GMP 符合性判定。未完善内容可保存草稿，模拟提交必须先完成校验和规程/变更依据。
- 记录预览随配置更新，展示样品身份、计划与实际时间、交接、检验和独立的程序/样品/分析/结果/继续加工状态；不预填合格，不将取样结果当作批次放行。
- 编辑、复制隔离、启停、只读、草稿/模拟提交及刷新恢复沿用现有交互，不请求业务 API。
- 过程取样的 01–07 配置区采用 Tab 布局，每次进入操作默认展示“01 取样方案与触发规则”，仅显示当前面板；切换 Tab 保留全部编辑，支持键盘导航，只读/停用时仍可切换查看。基础属性、变更说明和保存/校验/预览操作保持公共展示，窄屏标签栏局部横向滚动。

## 生成批号工艺静态演示（2026-09-10）

范围澄清：用户明确“演示用，生成 mock 和静态演示数据即可”。下拉报告、章节摘录和映射均为内置演示，不读取报告中心真实数据，不接入文档识别或持久化。

- 在版本历史右侧增加“生成批号工艺”；只读权限下禁止生成。
- 通过下拉框选择研发类 CMC 示例报告，填写目标批号，预览适用操作及示例条款，允许勾选裁剪；报告切换重新加载其默认选择，批号空白或未选操作时禁止生成。
- 至少提供两份具有不同工艺路线和参数的示例报告，生成结果确实随报告及勾选项变化。
- 生成独立的批 GxP 会话草稿，仅包含选中操作及所属步骤；保留报告、版本、章节、示例摘录和通用操作编号，参数、事件、检查及取样配置可继续编辑。
- 原通用模板、各批草稿及其会话版本相互隔离，切换保留编辑。支持返回通用模板和导出包含来源与裁剪清单的演示 JSON。
- 明示静态示例及刷新清空；示例内容不代表真实报告结论或质量批准。既有保温/取样 Tab、校验和演示保存保持可用，全程零业务请求。
