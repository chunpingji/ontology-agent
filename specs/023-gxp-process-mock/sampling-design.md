# 过程取样配置设计

适用入口：`/mock/gxp-process` → 反应与保温反应 → 过程取样（OP11.03）。面向化学合成原料药操作模板，沿用页面的阶段适用性字段；企业需按品种、开发阶段及批准规程确认具体要求。

## 已核对的依据

2026-09-10 下载并读取 [ICH Q7 官方 PDF](https://database.ich.org/sites/default/files/Q7%20Guideline.pdf) 与 [ICH Q9(R1) 官方 PDF](https://database.ich.org/sites/default/files/ICH_Q9%28R1%29_Guideline_Step4_2023_0126_0.pdf)。以下界面字段是落实原则的设计，不是 ICH 指定的统一表单或数值限度。

| 配置 | 来源及设计边界 |
|---|---|
| 方案、版本、批准依据、用途和代表性论证 | Q7 §8.30–8.34、§11.12；Q9(R1) §3–4。由开发/历史数据及质量风险评估支持，关键控制点/方法由质量部门批准。 |
| 触发事件、首次取样、间隔和允许时间窗 | Q7 §8.30、§8.34。数值留空；取样频率不沿用料温记录频率。 |
| 点位、相别、位置、单份量、份数和混合规则 | Q7 §8.34。多点和混合样需论证，不套用来料容器抽样公式。 |
| 方法、取样前准备、防污染及设备恢复 | Q7 §8.35。密闭/开口、预处理及气体保护由工艺决定。 |
| 即时处理、容器、保存运输、最长保存时间及稳定性依据 | Q7 §8.35。避免继续反应、吸湿、挥发和氧化改变样品；温度、处理时间不预设为法规数值。 |
| 检验项目、方法版本、单位/基准、接受准则和用途 | Q7 §8.30–8.33、§11.12、§6.60。面积百分比不能自动当作质量含量或转化率。 |
| 样品标识、批号、取样/接收时间、人员、原始数据和复核 | Q7 §6.52、§6.60、§11.11、§11.14。配置阶段展示待填记录，不生成实际执行事实。 |
| 监测调整、OOS、分析无效、样品异常及重取样/复测 | Q7 §8.33、§8.36、§11.15。监测/调整用过程检验通常不要求 OOS 调查；终点/规格用途按适用批准程序处理。例外不得掩盖偏差或使后续结果覆盖原始记录。 |

## 状态与行为

方案以当前操作的 `sampling` 配置保存，切换操作保留状态，复制使用深拷贝；草稿快照包括方案。刷新恢复示例，无后端持久化、电子签名或自动规则执行。

默认采用事件触发、过程监测用途作为可编辑示意；数值、文件版本、批准引用留空。校验显示缺口，允许附变更说明保存未完善草稿；模拟提交需完整配置、规程来源和变更说明。终点模式须有必需的终点检验项目；固定间隔需正数；数量为正数，份数为正整数，时间窗非负；混合样和即时处理按选择校验依赖字段。

预览包含方案摘要、点位要求、检验准则和空白记录字段。取样程序符合性、样品适用性、分析运行、结果判定、继续加工决定分别保持待确认/未检验/未决；继续加工条件为配置文字，不产生实际放行。异常处置保留原始样品、结果、调查、重取样/复测和授权的追溯关系。

界面以七个 Tab 展示四个专用配置区及已有时间事件、操作检查、审核预案；默认第一项，切换只影响当前展示，表单数据继续由当前操作持有。标签位于禁用表单之外，只读/停用时允许切换查看。基础属性、变更说明、校验、预览和保存保持公共展示。沿用主题变量和现有 Tabs 组件，标签栏与宽表局部滚动，手机/窄屏字段换行。
