# 实施计划

1. 固化原件哈希、原文坐标、静态关系图谱和显式谓词路径模板。
2. 独立服务校验输入与匹配模板，复用 OutputNode 和 GeneratedReport；演示专用渲染器继承参考样例格式。
3. 前端按服务端演示标记选择静态工作区；复用目录、WordViewer、RelationPanel、Sheet。
4. 隔离测试源版本、缺失输入、生成/持久化/重试、权限及不调用模型，验证前端类型与交互。

不新增数据库表。演示制品存 data/reports/batch-demo，文件失败/事务失败时清理本次制品。
报告保存图谱、模板、输出 AST 和哈希，保存行为审计。GET 不写数据库或制品。

版式追加：演示专用 renderer 从参考样例读取段落、表格和分节格式，创建干净 DOCX，
只复制格式与所需主题；静态契约仍决定内容。OutputNode.provenance_refs 保存版式
元数据供三处预览共用。有效 template_hash 包含参考 schema、样例字节及渲染版本。
验证样式、合并单元格、全部操作原文、旧样例事实不泄漏、版本冲突及历史兼容。

操作明细修正：人工核对 66 条源操作与样例参数行的静态绑定，读取真实样例的参数名
和记录格式；计算名称与填写区分列。保留全部源操作，按参数拆物理行，复用各样例行
格式，操作描述与签署按源操作合并。前端和 DOCX 共用同一 AST，定向验证跨行合并、
每行参数与单位、全部原文完整性、绑定错位拒绝及旧版本失效。

后续特化顺序：增加可选 profile 与普通内核隔离 → 共享模板上下文及专用页 →
隔离测试 → 带预期哈希的目标草稿原位更新及审计 → 只读核验数据库。
用户明确要求保留既有模板 URL；草稿原位特化为此请求的有界例外，已发布模板仍拒绝。

页眉和 A14 内容修正：按样例分节复制页眉，A14 的操作记录表使用被明确授权的样例
内容与原始表格结构，预览 AST 保存逐段/逐 run 样式及来源。其他填充表格在文字不变时
保留 run；替换文字时明确继承中文/西文字体与字号。升级渲染版本，校验模板范围、
内容/格式一致性、未授权样例内容隔离、旧版本失效，并完成 Word 和浏览器验证。
